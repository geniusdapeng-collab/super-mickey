## 关于项目

**超级小香宝**（英文名：Xiangxiang SuperMickey）是一个 AI 视频制作系统，
名字灵感来源于北欧神话中的 Bifrost（彩虹桥），
它将用户的创意与渲染引擎连接起来，让想象变成现实。

这个名字献给项目创建者的女儿——**香香**，
希望她的人生像彩虹一样多彩绚烂。

---

## 技术架构

- 前身：Hyperreal AI Video System (HAVS) / Nirath Master Pipeline
- 核心引擎：Seedance 2.0
- 编排系统：Saga Orchestrator
- 特色能力：山海经/国漫、超现实渲染、多方案比稿
