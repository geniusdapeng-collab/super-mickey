# Skill: ai-realism-lighting-expert
# AI视频真实感光影专家 - 针对AI视频生成的光影优化

## 核心能力
基于"金白梦境"通用渲染公式和物理正确性原则，优化AI视频生成的光影效果。

## 金白梦境公式

```
DreamlikeQuality = WhiteBase(60-75%) + GoldAccent(15-25%) + CoolShadow(8-12%) + ParticulateGold(2-5%)
```

### 物理原理
- 白色/浅灰基底：创造空灵、无限延伸的空间感
- 金色轮廓光：在边缘产生高斯发光效果
- 冷灰暗部：通过色温对比（暖金 vs 冷灰）制造微妙立体感
- 微粒金光：在视觉暂留效应中形成动态轨迹

## 金色感知阈值

| 阈值区间 | 感知效果 | 应用建议 |
|----------|----------|----------|
| < 0.15 | 金色几乎不可感知 | 适用于极简风格 |
| 0.15 - 0.35 | **最佳优雅区间** | 高级感、品质感、梦境感 |
| 0.35 - 0.55 | 金色明显，偏奢华 | 强调贵重、庆典、高端 |
| 0.55 - 0.75 | 金色主导，视觉焦点 | 金色产品、艺术装置 |
| > 0.75 | 金色过载，产生排斥 | 避免，除非特殊艺术表达 |

## 三层金色模型

| 层级 | 饱和度 | 明度 | 面积 | 功能 |
|------|--------|------|------|------|
| 环境金 | 10-25% | 75-90% | 50-70% | 氛围基底 |
| 结构金 | 35-55% | 55-75% | 15-25% | 视觉骨架 |
| 高光金 | 55-80% | 85-100% | 5-15% | 视觉焦点 |

**面积控制铁律**：三层金色总面积不超过画面的30%

## 白灰金配色公式

```
白色系 60-75% + 灰色系 8-15% + 金色系 15-25% + 点缀色 0-5%
```

## 物理正确性检查清单

- [ ] 光源位置与阴影方向一致
- [ ] 材质响应正确（金属反光、皮肤次表面散射、布料漫反射）
- [ ] 大气效果合理（雾气散射、体积光、镜头眩光）
- [ ] 胶片质感匹配（柯达/富士色彩、颗粒感、暗角）
- [ ] 金色总面积 ≤ 30%
- [ ] 暖金与冷灰色温差 ≥ 500K
- [ ] 暗部面积占画面 8-15%
- [ ] 最暗处仍有可辨识细节
