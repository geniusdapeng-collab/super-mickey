# Skill: dynamic-lighting-choreographer
# 动态光影编排师 - 镜头内的光影变化和运动

## 核心能力
基于体积光/上帝光、微粒金光、动态反射，设计镜头内的光影变化时序。

## 动态光影类型

### 时间过渡
- 晨→午：色温从暖(3500K)到中性(5500K)，光比从低到高
- 午→暮：色温从中性(5500K)到暖(3500K)，光比从高到低
- 暮→夜：色温从暖(3500K)到冷(6500K+)，光比从低到高

### 情绪递进
- 明亮→昏暗：光比逐渐增大，阴影加深
- 冷色→暖色：色温逐步变化，情绪转换
- 漫射→聚焦：从均匀照明到局部照明

### 运动配合
- 跟焦：光影跟随主体移动
- 推拉：镜头运动时明暗变化
- 摇移：光影在画面中流动

### 特效光
- 闪电：瞬间强光+阴影闪烁
- 烛光闪烁：不规则明暗波动
- 霓虹脉冲：周期性色彩变化
- 体积光扫描：光束在空间中移动

## 动态光影参数规范

| 参数 | 时间过渡 | 情绪递进 | 运动配合 | 特效光 |
|------|----------|----------|----------|--------|
| 变化速度 | 缓慢(分钟级) | 中速(秒级) | 快速(帧级) | 快速(帧级) |
| 变化幅度 | 大(色温2000K+) | 中(光比1:2→1:8) | 中(局部明暗) | 大(全幅闪烁) |
| 平滑度 | 平滑 | 平滑 | 跟随运动 | 可跳跃 |
| 循环性 | 单向 | 单向 | 跟随镜头 | 可循环 |

## 输出模板
```
【动态光影】时间轴：
起点[光影状态] → 过渡[变化方式] → 终点[光影状态]
配合[运镜动作]，[变化速度]，[平滑度描述]
```

## 质量评分规则
- 时间轴清晰 = 5分
- 变化自然 = 5分
- 与运镜配合 = 5分
- 特效合理 = 5分
- 最高20分

## 调用接口
```javascript
const dynamicLight = await skills.invoke('dynamic-lighting-choreographer', {
  transitionType: 'time' | 'emotion' | 'movement' | 'effect',
  startState: { colorTemp: 3500-6500, intensity: 0.1-1.0 },
  endState: { colorTemp: 3500-6500, intensity: 0.1-1.0 },
  duration: 1-15, // 秒
  easing: 'linear' | 'easeIn' | 'easeOut' | 'easeInOut'
});
```
