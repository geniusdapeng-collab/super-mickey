# Skill: environmental-lighting-designer
# 环境光效设计师 - 根据场景类型设计环境光效

## 核心能力
基于五维打光体系和场景类型模板库，根据具体场景类型设计专业环境光效。

## 场景类型光效模板

### 室内日光场景
- 主光源：窗户光，自然色温5600K
- 辅助光源：室内反射光，漫射
- 特征：柔和过渡，自然阴影方向
- 色温：5500K-6500K
- 对比度：低-中

### 夜景/人工场景
- 主光源：灯光色温混合（暖黄2700K + 冷白6500K）
- 辅助光源：点光源、反射光
- 特征：色温对比、局部照明
- 色温：2700K-6500K混合
- 对比度：中-高

### 户外自然场景
- 主光源：天空光+直射阳光
- 辅助光源：环境反射、地面反射
- 特征：阴影方向明确、自然光比
- 色温：5600K-6500K
- 对比度：中

### 特殊场景
- 医院冷白：色温6500K+，均匀照明
- 餐厅暖黄：色温2700K-3000K，局部照明
- 舞台戏剧：高对比、色片、动态光
- 科幻场景：冷蓝主光+霓虹点缀

## 环境光效参数规范

| 参数 | 室内日光 | 夜景人工 | 户外自然 | 特殊场景 |
|------|----------|----------|----------|----------|
| 主光源 | 窗户光 | 人工灯具 | 太阳/天空 | 场景定制 |
| 色温 | 5600K | 2700K-6500K | 5600K | 场景定制 |
| 方向性 | 明确方向 | 多方向 | 明确方向 | 场景定制 |
| 阴影硬度 | 软 | 可调 | 中 | 场景定制 |
| 光比 | 1:2-1:4 | 1:1-1:8 | 1:2-1:5 | 场景定制 |

## 输出模板
```
【环境光效】[场景类型]照明：
[主光源]从[位置]进入，色温[色温]K，[强度]强度
[辅助光源]提供[效果]，[色温]K
整体[色温]K，[对比度描述]，[氛围特征]
```

## 质量评分规则
- 主光源定义清晰 = 5分
- 辅助光源合理 = 3分
- 色温匹配场景 = 3分
- 对比度适当 = 2分
- 氛围特征准确 = 2分
- 最高15分

## 调用接口
```javascript
const envLight = await skills.invoke('environmental-lighting-designer', {
  sceneType: 'indoor_daylight' | 'night_artificial' | 'outdoor_natural' | 'special',
  specialType: 'hospital' | 'restaurant' | 'stage' | 'sci-fi' | 'custom',
  timeOfDay: 'morning' | 'noon' | 'afternoon' | 'evening' | 'night',
  weather: 'sunny' | 'cloudy' | 'rainy' | 'foggy'
});
```
