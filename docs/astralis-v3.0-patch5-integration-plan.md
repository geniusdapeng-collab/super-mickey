# ASTRALIS v3.0-patch5 集成方案 — 5大新模块融入片头系统

## 当前状态
- v3.0-patch4: 974字符 / 980上限（99.4%利用率）
- 问题：5大新模块需要Prompt空间，但余量仅6字符

## 方案A：单镜头极致压缩（风险高）
在974字符基础上，继续优化压缩算法，挤出新模块空间。
- 风险：可能丢失核心视觉元素
- 适用：小幅度优化（如只加音效描述）

## 方案B：双镜头片头（推荐）
拆分为2个镜头，每个镜头独立Prompt：

### 镜头1：黄金3秒爆发（3秒）
**Prompt目标**：500-600字符
**内容**：
- 超写实锚定词（精简版）
- 双恒星爆发 + 磁丝树全景
- 孢子粒子冲击
- 运镜：extreme_wide + fast_dolly_in + 磁场线扫过
- 音效：低频磁场共鸣骤起
- 九尾狐轮廓浮现

### 镜头2：标题成形 + 出品人（6秒）
**Prompt目标**：900-950字符
**内容**：
- Nirath永夜裂谷场景
- 磁流体标题成形
- 小G仰望
- 出品人"by Genius"
- 5维质感体系
- 节奏密度控制

## 方案C：三镜头片头（最大信息量）
拆分为3个镜头：

### 镜头1：爆发帧（2秒）
- 双恒星爆发
- 磁丝树全景
- 孢子冲击

### 镜头2：悬念帧（3秒）
- 九尾狐完整显现
- 磁流体动态
- 小G反应

### 镜头3：冲击帧（4秒）
- 标题成形
- 出品人呈现
- 余韵消散

## 技术实现

### 1. 片头拆分器（ASTRALIS Opening Splitter）
```javascript
function splitOpening(intoShots = 2) {
  if (intoShots === 2) {
    return {
      shot1: { duration: 3, focus: 'hook_3_second', promptTarget: 550 },
      shot2: { duration: 6, focus: 'title_formation', promptTarget: 950 }
    };
  } else if (intoShots === 3) {
    return {
      shot1: { duration: 2, focus: 'burst', promptTarget: 450 },
      shot2: { duration: 3, focus: 'suspense', promptTarget: 700 },
      shot3: { duration: 4, focus: 'climax', promptTarget: 900 }
    };
  }
}
```
