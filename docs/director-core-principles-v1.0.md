# 山海经导演编剧核心原则 v1.0

> **创作铁律**：我们制作的不是"异兽百科介绍片"，而是**冒险类 CG 动画**。
> 每集必须服务于一个核心使命——**讲述AgentX在 Nirath 星球上的冒险与成长，激励现实生活中的每个人勇敢前进。**

---

## 一、核心定位（不可动摇）

| 维度 | 定义 |
|------|------|
| **类型** | 冒险类 CG 动画 |
| **主角** | 男主AgentX |
| **世界观** | Nirath 星球 × 山海经：异兽志 |
| **精神内核** | **冒险**——勇敢与成长 |
| **现实意义** | 激励现实生活中每个人的前进 |
| **创作铁律** | 每个故事必须服务于这条主线 |

### 核心命题
> "AgentX的英雄之旅 = 每个观众内心的冒险寓言"

---

## 二、每集必备五要素

### 1. 冒险触发（The Call）
- **为什么AgentX必须面对这只异兽？**
- 不能是"路过顺便看看"，必须是**不得不面对**的处境
- 触发点：生存威胁 / 使命召唤 / 情感羁绊 / 自我证明

### 2. 抗拒与恐惧（The Refusal）
- AgentX最初的**恐惧、犹豫、不自信**
- 真实展现脆弱——勇敢不是没有恐惧，而是带着恐惧前行
- 这是观众产生**代入感**的关键锚点

### 3. 试炼与互动（The Ordeal）
- **异兽不只是"被展示"，而是AgentX成长的试炼者/镜子/催化剂**
- 异兽的能力、习性、弱点必须与AgentX的内心困境形成**隐喻关系**
- 战斗/追逐/解谜/对话——任何形式的对抗都是**内心挣扎的外化**

### 4. 觉醒与蜕变（The Revelation）
- AgentX在临界点领悟到**突破自我的关键**
- 不是"打赢了"，而是**"理解了""接纳了""超越了"**
- 蜕变时刻必须有**情感重量**——观众要为AgentX的成长动容

### 5. 回归与激励（The Return）
- **回到"激励现实观众"**
- 结尾落点：AgentX的成长对观众意味着什么？
- 每个观众看完都应该觉得：**"我也能像AgentX一样勇敢"**

---

## 三、异兽叙事功能定义

### 异兽不是 Boss，而是**成长的催化剂**

| 异兽类型 | 叙事功能 | 对AgentX的意义 |
|---------|---------|-------------|
| **试炼者** | 测试AgentX的勇气/智慧/善良 | 逼迫他突破舒适区 |
| **镜子** | 反映AgentX内心的恐惧或渴望 | 让他直面真实的自己 |
| **导师** | 以异兽的方式传授生存法则 | 获得 Nirath 世界的智慧 |
| **同伴** | 从敌对到理解，建立跨物种羁绊 | 学会信任与共情 |
| **寓言体** | 异兽的遭遇本身就是一则寓言 | AgentX从中照见自己的人生 |

### 核心规则
> **如果这只异兽可以被替换成另一只而不影响故事——这个故事是失败的。**
> 每只异兽必须是**不可替代的、唯一的成长催化剂**。

---

## 四、情感节拍标准

### 每集必须覆盖的情绪光谱

```
1. 好奇/期待     → 开场，吸引入场
2. 恐惧/紧张     → 遭遇异兽，建立张力
3. 挫败/绝望     → 试炼失败，跌入谷底
4. 坚持/希望     → 不放弃，找到突破口
5. 顿悟/释放     → 觉醒时刻，情感高潮
6. 温暖/力量     → 结尾，带着力量回归
```

### 情绪曲线模板（60秒短片）

| 时间段 | 情绪目标 | 观众感受 |
|--------|---------|---------|
| 0-8s   | 好奇     | "这是什么地方？" |
| 8-20s  | 紧张     | "AgentX遇到危险了！" |
| 20-35s | 挫败     | "他能撑过去吗？" |
| 35-45s | 顿悟     | "原来如此！" |
| 45-55s | 高潮     | "太燃了！" |
| 55-60s | 温暖     | "我也想变勇敢" |

## 五、导演系统注入清单

### 剧本创作模块（Story Engine）
- [ ] 每集剧本必须通过"五要素检查"
- [ ] 异兽的叙事功能必须在剧本阶段明确标注
- [ ] 结尾必须有"现实激励落点"台词或画面
- [ ] 禁止"旁观者视角"——AgentX必须参与、必须改变

### 镜头设计模块（Shot Design）
- [ ] 开场镜头必须建立"冒险感"（FPV 穿越 / 神秘环境揭示）
- [ ] 试炼阶段必须有"一镜到底"增强沉浸感
- [ ] 觉醒时刻必须有"梦境式镜头"（时间变慢、光线变化、色彩偏移）
- [ ] 结尾镜头必须回归"人"——AgentX的表情特写，让观众与他连接

### 台词/旁白模块（Dialogue/Narration）
- [ ] 每集至少有一句"金句"——可以被观众记住并分享的台词
- [ ] 旁白不是解说，而是**AgentX的内心独白**或**Nirath 世界的智慧之声**
- [ ] 结尾台词必须指向观众："你也能……"

### 角色塑造模块（Character）
- [ ] AgentX每集必须有**新的伤痕或标记**——成长的物理证据
- [ ] AgentX的装备/服装必须有**使用痕迹**——不是全新的，是经历过冒险的
- [ ] 异兽的眼神必须有**情绪层次**——不是单纯的凶恶或可爱，而是复杂的

### 音乐音效模块（Sound Design）
- [ ] 开场：神秘、期待感的环境音
- [ ] 试炼：心跳加速的紧张节拍
- [ ] 觉醒：情绪爆点的音乐高潮
- [ ] 结尾：温暖、余韵悠长的旋律，让观众走出影院后还在哼唱

---

## 六、质量闸机（必检项）

### 每集交付前必须通过

**闸机 1：冒险主线检查**
- [ ] AgentX是否经历了"触发→抗拒→试炼→觉醒→蜕变"完整弧线？
- [ ] 异兽是否是不可替代的成长催化剂？
- [ ] 结尾是否激励了现实观众？

**闸机 2：情感深度检查**
- [ ] 观众是否能感受到AgentX的恐惧？
- [ ] 觉醒时刻是否有情感重量？
- [ ] 结尾是否让观众产生"我也想勇敢"的冲动？

**闸机 3：不可替代性检查**
- [ ] 如果把这只异兽换成另一只，故事是否还成立？
- [ ] 如果是→失败，必须重新设计

**闸机 4：现实连接检查**
- [ ] 这个故事对 2026 年的观众有什么现实意义？
- [ ] 观众看完能带走什么？

## 七、失败案例警示

### ❌ 失败的异兽故事
> "AgentX在森林里遇到了饕餮，饕餮很凶猛，AgentX用智慧打败了它，然后离开了。"

**失败原因**：
1. 没有冒险触发——为什么是这只饕餮？
2. 没有抗拒与恐惧——AgentX一开始就准备好了？
3. 没有觉醒与蜕变——只是"打败了"，没有成长
4. 没有现实激励——观众带走什么？
5. 饕餮可替换——换成任何猛兽都一样

### ✅ 成功的异兽故事
> "AgentX为了寻找治疗暖暖的药草，必须穿越饕餮的领地。他害怕被吃掉（恐惧），但暖暖等不了（使命）。饕餮不是要吃他，而是要考验他是否配得上药草（试炼者）。AgentX发现饕餮曾经也是守护者，只是被背叛过（镜子）。他选择信任饕餮，而不是战斗（觉醒）。最后他带着药草和新的理解离开，也理解了'勇敢不是不害怕，是害怕时还选择前行'（激励）。"

**成功原因**：
- 冒险触发：拯救暖暖，不得不面对
- 抗拒：恐惧被吃掉
- 试炼：饕餮的考验
- 觉醒：理解饕餮的过去，选择信任
- 蜕变：从"战斗"到"理解"
- 现实激励：勇敢的定义
- 不可替代：只有饕餮能考验"信任"

## 八、执行流程

### Step 1: 选题阶段
- 选择异兽 → 定义其**叙事功能**（试炼者/镜子/导师/同伴/寓言体）
- 确定AgentX的**成长主题**（信任/放下/坚持/接纳/牺牲/选择）
- 验证：这只异兽是否**不可替代**？

### Step 2: 剧本阶段
- 按"五要素"构建故事弧线
- 每段标注情绪目标
- 结尾必须有"现实激励落点"

### Step 3: 预生产阶段
- 每镜检查是否服务于情绪曲线
- 运镜方案必须增强"冒险感"
- 角色 Prompt 必须包含"成长痕迹"

### Step 4: 渲染与后期
- 音乐音效严格按情绪节拍配置
- 一镜到底镜头必须用于觉醒或高潮
- 结尾必须有AgentX表情特写

### Step 5: 交付审查
- 通过"质量闸机"四项检查
- 队长终审：这个故事是否激励了你？
