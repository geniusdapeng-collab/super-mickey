## 三、字段详细规范

### 3.1 【约束】constraint

**业务含义**：画面基础参数约束，告诉渲染引擎"这是什么格式的画面"。

**应包含内容**：
```
16:9 cinematic, 24fps cinematic, no text, no subtitle, no caption, no watermark
```

**生成方式**：
- **主来源**：PromptFusionAgent system prompt 硬编码模板
- **辅助**：画幅比例从剧本 metadata（aspectRatio）传入

**在渲染中的作用**：
- Seedance 解析画幅比例（16:9）
- 设置帧率参数（24fps cinematic）
- 基础禁止项（text/subtitle/watermark）

---

### 3.2 【基础】baseline

**业务含义**：画质基础描述词，决定画面质感等级。

**应包含内容**：
```
hyperrealistic, ultra-detailed, high dynamic range, detail in highlights and shadows, film grain, 35mm texture, cinematic film
```

**生成方式**：
- **主来源**：PromptFusionAgent system prompt 硬编码模板
- **风格适配**：根据用户指定的"全写实/好莱坞质感"调整

**在渲染中的作用**：
- 告诉 Seedance "这是电影级画质"
- 控制纹理细节级别（ultra-detailed）
- 光影层次（HDR, detail in highlights and shadows）

---

### 3.3 【场景】scene

**业务含义**：具体环境空间描述，这是画面"在哪里发生"。

**应包含内容**（按优先级）：
1. **地点**：医院健康宣教室 / 三甲医院检验科走廊 / 医生诊室
2. **空间结构**：走廊纵深约十五米 / 室内空间纵深约四米
3. **关键物体**：木质讲台 / 不锈钢检验窗口 / 听诊器与血压计
4. **材质细节**：墙面乳胶漆质感 / 地面浅色耐磨塑胶材质
5. **时间/天气**：白天自然窗光 / 夜间人工照明

**生成方式**：
- **主来源**：SceneDesignAgent（LLM生成，基于剧本场景描述）
- **PromptFusion 融合**：LLM 创造性融合
- **写实检查**：强制替换科幻/抽象词汇

**在渲染中的作用**：
- Seedance 根据描述生成对应 3D 环境
- 光影反射基于材质（不锈钢台面反射冷光）
- 空间深度影响景深效果

---

### 3.4 【灯光/照明】lighting ⭐ 新增

**业务含义**：专业灯光设计，决定画面的"光影质感"。这是摄影师最核心的控制手段之一。

**应包含内容**（按优先级）：
1. **主光（Key Light）**：方向+色温+光质
   - 方向：右侧45度顶光 / 正前方柔光 / 左侧逆光
   - 色温：5600K冷白光 / 3200K暖光 / 4500K自然光
   - 光质：硬光（直射）/ 柔光（漫射）/ 柔光箱
2. **补光（Fill Light）**：填充阴影，控制光比
   - 方向：左前侧反光板 / 正面漫射光
   - 色温：通常比主光略暖或同温
   - 强度：为主光的1/2到1/4（光比2:1到4:1）
3. **背景光/轮廓光（Back Light/Rim Light）**：分离人物与背景
   - 方向：人物后方/侧后方
   - 效果：勾勒轮廓 / 增强空间层次
4. **特效光（Special Light）**：氛围光、窗户光、反射光等

**标准格式**：
```
主光：右侧45度顶光 5600K冷白光，柔光箱漫射；补光：左前侧反光板 3200K暖光，填充阴影；背景光：轮廓光分离人物与背景；特效：检验窗口玻璃微弱反射光
```

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成（基于场景类型+情绪+时间）
- **场景映射**：不同场景类型有默认灯光配置（医院冷白光/宣教室暖白光）

**在渲染中的作用**：
- Seedance 根据灯光描述生成光影效果
- 主光方向决定面部阴影形状
- 色温影响整体色调（冷=严肃/暖=温馨）
- 光比决定画面对比度

---

### 3.5 【构图】composition ⭐ 新增

**业务含义**：画面的视觉组织结构，决定"观众看哪里"。

**应包含内容**：
1. **景别**：
   - 特写（脸部/眼睛）/ 近景（胸上）/ 中景（膝上）/ 全景（全身）/ 远景（环境）
2. **主体位置**：
   - 黄金分割点 / 画面中央 / 三分法交点 / 对角线构图
3. **线条引导**：
   - 走廊纵深感由近及远 / 桌面水平线 / 人物垂直线
4. **画框边缘**：
   - 左侧留白1/4给背景信息 / 顶部留天头 / 底部留地线
5. **对称/非对称**：对称构图（庄重）/ 非对称（动态）

**标准格式**：
```
景别：中景（膝上）；主体位置：画面黄金分割右1/3处；线条引导：走廊纵深感由近及远；画框边缘：左侧留白1/4给背景信息
```

**在渲染中的作用**：
- 告诉 Seedance 主体在画面中的位置和大小
- 影响视觉焦点和注意力引导
- 景别决定情感距离（特写=亲近，远景=疏离）

---

### 3.6 【色彩/色调】color_palette ⭐ 新增

**业务含义**：画面的色彩方案，决定"画面是什么颜色的"。

**应包含内容**：
1. **主色调**：冷白偏青 / 暖黄偏橙 / 中性灰
2. **辅助色**：暖木色讲台点缀 / 金属银灰 / 绿植色彩
3. **肤色处理**：自然偏暖 / 苍白病态 / 红润健康
4. **饱和度**：高饱和（鲜艳）/ 中等偏低（写实）/ 低饱和（压抑）
5. **对比度**：高对比（戏剧性）/ 中等（自然）/ 低对比（柔和）
6. **特殊调色**：电影感青橙调 / 复古暖调 / 冷峻蓝调

**标准格式**：
```
主色调：冷白偏青（医院感）；辅助色：暖木色讲台点缀；肤色：自然偏暖；饱和度：中等偏低，避免过度鲜艳；对比度：中高，保持清晰层次
```

**在渲染中的作用**：
- 控制 Seedance 整体色彩倾向
- 色调影响情绪（冷=疏离/暖=亲切）
- 饱和度影响真实感（写实=低饱和，动画=高饱和）

---

### 3.7 【景深】depth_of_field ⭐ 新增

**业务含义**：焦点前后的清晰范围，决定"画面哪里清晰哪里模糊"。

**应包含内容**：
1. **焦点位置**：人物面部 / 手部动作 / 道具细节
2. **光圈值（f值）**：f/1.4（极浅景深）/ f/2.8（中等）/ f/8（全景深）
3. **前景虚化**：讲台边缘轻微虚化 / 无前景
4. **背景虚化**：走廊纵深渐变模糊 / 适度虚化可辨
5. **层次分离**：前景-中景-背景三层 / 中景-背景两层

**标准格式**：
```
焦点：人物面部；景深：中等（f/2.8），背景适度虚化可辨；前景：无；背景：走廊纵深渐变模糊；层次：中景（人物）-背景两层
```

**在渲染中的作用**：
- 控制 Seedance 焦点位置
- 浅景深突出主体，深景深展现场景
- 虚化程度影响电影感

---

### 3.8 【运镜】camera_movement ⭐ 新增（从【动作】拆分）

**业务含义**：镜头本身的运动方式，这是"摄影机在怎么动"。

> **注意**：与【动作】拆分后，【动作】只描述角色动作，【运镜】只描述镜头运动。

**应包含内容**：
1. **运动方式**：
   - 推（Dolly In）/ 拉（Dolly Out）/ 摇（Pan）/ 移（Truck）/ 跟（Follow）/ 升降（Crane）
2. **速度**：缓慢（0.3m/s）/ 中等 / 快速
3. **稳定性**：稳定器（平滑）/ 手持（呼吸感/微晃）/ 固定机位
4. **时间分布**：
   - 0-3s：稳定器缓慢推近 → 3-6s：固定机位 → 6-10s：手持微晃跟拍

**标准格式**：
```
0-2s：稳定器缓慢推近（0.3m/s）→ 2-6s：固定机位 → 6-10s：手持微晃跟拍（呼吸感，幅度±2度）
```

**生成方式**：
- **主来源**：VisualLanguageAgent（根据场景类型推断运镜）
- **PromptFusion 融合**：LLM 根据情绪+场景调整

**在渲染中的作用**：
- 告诉 Seedance 镜头如何运动
- 推近=强调/关注，拉出=环境展示
- 手持=真实感/纪录片感，稳定器=专业感

### 3.9 【角色】character

**业务含义**：画面中的人物身份、姿态、表情。

> **注意**：v2.1.4-fix9-P15 将服装和化妆拆分出去，【角色】只保留身份、姿态、表情。

**应包含内容**：
1. **身份**：健康科普主讲人 / 穿警服的陈女士
2. **姿态**：站姿挺拔 / 坐姿端正 / 行走中
3. **表情**：关切 / 严肃 / 微笑 / 警示

**标准格式**：
```
穿警服的陈卓女士，健康科普主讲人，站姿挺拔，表情关切
```

**生成方式**：
- **主来源**：ScriptEngine 剧本中的角色设定
- **PromptFusion 融合**：LLM 根据场景类型调整姿态和表情

**在渲染中的作用**：
- Seedance 根据描述生成人物形象
- 表情影响观众情感连接

---

### 3.10 【服装】costume ⭐ 新增（从【角色】拆分）

**业务含义**：角色的详细服装描述，影响画面色调和角色可信度。

**应包含内容**：
1. **外套**：藏青色警服外套（毛呢质地，肩章完整）
2. **内搭**：浅蓝色衬衫（棉质，领口整洁）
3. **下装**：黑色西裤（修身剪裁）
4. **鞋履**：黑色皮鞋（抛光）
5. **配饰**：肩章 / 领花 / 口袋细节

**标准格式**：
```
藏青色警服外套（毛呢质地，肩章完整），内搭浅蓝色衬衫（棉质，领口整洁），黑色西裤，黑色皮鞋
```

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成（基于角色设定）
- **服装锁定**：强制使用原始角色设定中的服装（禁止LLM擅自更改）

**在渲染中的作用**：
- 服装颜色影响画面色调
- 质地细节增加真实感
- 配饰增强角色身份辨识度

---

### 3.11 【化妆】makeup ⭐ 新增

**业务含义**：角色的妆容和发型细节。

**应包含内容**：
1. **发型**：短发整齐（黑色，长度及耳）/ 长发披肩 / 盘发
2. **妆容**：素颜淡妆 / 自然妆容 / 无夸张妆容
3. **眉毛**：自然 / 修整
4. **唇色**：淡粉 / 自然色
5. **肤色**：自然 / 偏白 / 偏黄

**标准格式**：
```
短发整齐（黑色，长度及耳），素颜淡妆，眉毛自然，唇色淡粉
```

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成（基于角色设定和场景）

**在渲染中的作用**：
- 妆容影响角色气色和精神状态
- 发型影响角色形象一致性

### 3.12 【动作】action

**业务含义**：角色的具体动作，这是"人在做什么"。

> **注意**：v2.1.4-fix9-P15 将运镜拆分出去，【动作】只描述角色动作。

**应包含内容**：
1. **手势**：右手自然抬起至胸前做强调手势 / 双手交叠置于膝上
2. **步伐**：沿走廊缓步前行 / 站立不动
3. **视线**：目光直视镜头 / 侧头指向检验窗口
4. **身体姿态**：身体微微前倾 / 转身面向镜头

**标准格式**：
```
右手自然抬起至胸前做强调手势，左手自然下垂，身体微微前倾，目光直视镜头
```

**生成方式**：
- **主来源**：VisualLanguageAgent + PromptFusionAgent
- **写实检查**：禁止科幻/抽象动作

**在渲染中的作用**：
- 角色动作影响画面动态
- 手势辅助表达台词内容
- 视线方向决定观众注意力焦点

---

### 3.13 【道具】props ⭐ 新增

**业务含义**：画面中的关键道具，增强场景真实感和叙事细节。

**应包含内容**：
1. **手持物**：空白A4文件夹 / 不锈钢保温杯 / 听诊器
2. **桌面物品**：血压计 / 空白报告单 / 中性笔
3. **背景物件**：木质讲台 / 不锈钢检验窗口 / 健康宣传展板

**标准格式**：
```
手持：空白A4文件夹（白色，无文字）；背景：木质讲台（表面有细微划痕），不锈钢保温杯
```

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成（基于场景类型）
- **写实检查**：道具必须与场景匹配（医院=医疗器械）

**在渲染中的作用**：
- 道具增强场景真实感
- 手持物丰富角色动作
- 背景物件填充画面层次

---

### 3.14 【定妆照】portraits

**业务含义**：角色定妆照引用路径，用于 Seedance 角色一致性渲染。

**应包含内容**：
```
image://characters/chen-zhuo/portraits/chen-zhuo-front.png
image://characters/chen-zhuo/portraits/chen-zhuo-threeQuarter.png
image://characters/chen-zhuo/portraits/chen-zhuo-closeup.png
image://characters/chen-zhuo/portraits/chen-zhuo-side.png
```

**生成方式**：
- **主来源**：系统从 `charactersDir` 自动注入
- **路径规则**：`image://characters/{character_id}/portraits/{filename}.png`

**在渲染中的作用**：
- Seedance 读取定妆照作为角色参考图
- 确保跨镜头角色形象一致

---

### 3.15 【台词】dialogue

**业务含义**：角色直接说的话，用于 Seedance 原生口型渲染。

**应包含内容**：
```
【台词】"大家好，我是陈卓。今天说说横纹肌溶解的症状。"
```

**格式要求**：
- 必须用 `"` 包裹
- 不要写"画外音""旁白"
- 角色直接对镜头说话

**生成方式**：
- **主来源**：ScriptEngine 剧本台词生成
- **PromptFusion 提取**：从剧本台词字段提取

**在渲染中的作用**：
- Seedance 原生口型同步
- 台词与画面同步渲染

---

### 3.16 【时间轴】timeline

**业务含义**：镜头内部的微观导演调度，描述运镜/构图/情绪/灯光如何随时间变化。

**应包含内容**（分段式，至少3段）：
```
0-2s: 全景 establishing，环境光，冷静专业 
→ 2-5s: 推近中景，人物入画，暖光渐入，亲切感 
→ 5-8s: 特写脸部，侧光强化，台词高潮，警示感峰值 
→ 8-10s: 缓慢拉出，柔光平复，安心收尾
```

**每段必须包含**：时间区间、运镜动作、构图变化、情绪走向、灯光变化

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成
- **system prompt 指导**：明确要求按5维度分段

**在渲染中的作用**：
- 告诉 Seedance "这个镜头内部有变化"
- 指导镜头运动节奏
- 控制光影变化

---

### 3.17 【情绪】mood

**业务含义**：情绪氛围关键词，影响画面色调和角色表情。

**应包含内容**：
```
冷静，专业，关切，警示，安心
```

**生成方式**：
- **主来源**：VisualLanguageAgent 根据情绪阶段推断
- **PromptFusion 融合**：LLM 根据场景内容调整

**在渲染中的作用**：
- 影响 Seedance 色调生成
- 影响角色表情
- 影响光影对比度

---

### 3.18 【节奏】pacing ⭐ 新增

**业务含义**：镜头的时间节奏感，决定"画面变化快慢"。

**应包含内容**：
1. **整体节奏**：沉稳中等 / 快速紧张 / 缓慢抒情
2. **开头**：缓慢引入（2s）/ 直接进入
3. **中段**：稍快推进（紧迫感）/ 平稳叙述
4. **高潮**：停顿强调（1s留白）/ 加速冲击
5. **结尾**：平缓收尾 / 突然切断

**标准格式**：
```
整体：沉稳中等节奏；开头：缓慢引入（2s）；中段：稍快推进（紧迫感）；高潮：停顿强调（1s留白）；结尾：平缓收尾
```

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成（基于场景类型+情绪阶段）

**在渲染中的作用**：
- 指导镜头运动速度
- 影响剪辑节奏
- 与【时间轴】配合控制变化节奏

---

### 3.19 【转场】transition ⭐ 新增

**业务含义**：与下一镜头的衔接方式，这是"怎么切到下一段"。

**应包含内容**：
1. **切镜（Cut）**：硬切，保持紧张感 / 直接切换
2. **淡入淡出（Fade）**：Fade In/Out，情绪过渡
3. **叠化（Dissolve）**：渐变过渡，时间流逝感
4. **划像（Wipe）**：线条划过，活泼感
5. **匹配剪辑（Match Cut）**：相似形状/动作衔接

**标准格式**：
```
切镜（硬切，保持紧张感）
```
或
```
淡出（1.5s，情绪平复过渡）
```

**生成方式**：
- **主来源**：PromptFusionAgent LLM 生成（基于情绪变化）
- **规则**：情绪突变=硬切，情绪延续=叠化，时间跳跃=淡入淡出

**在渲染中的作用**：
- 指导后期剪辑衔接方式
- 影响观众的心理预期
- 硬切=冲击，叠化=柔和，淡入淡出=时间流逝

---

### 3.20 【音频】audio

**业务含义**：环境音效 + 背景音乐描述，用于后期音频设计。

**应包含内容**：
```
医院室内低频环境音，轻微空调气流声，柔和科普配乐渐入，无嘈杂人声
```

**生成方式**：
- **主来源**：AudioDesignAgent（LLM根据场景环境生成）

**在渲染中的作用**：
- Seedance 目前不支持音频渲染，此字段用于后期制作
- 指导视频编辑添加背景音乐
- 指导音效师添加环境音

---

### 3.21 【负面约束】negative

**业务含义**：排除项，告诉 Seedance "画面中不要出现什么"。

**应包含内容**：

**中文侧**（L1层）：
```
禁止画面内出现任何文字（片头主副标题除外），含墙面/物品/文件/屏幕/服饰上的中英文、字母、数字、标点、商标、标签、招牌、路牌等一切可读内容；禁止一切印刷体、手写体、电子屏文字、发光字、字幕、水印
```

**英文侧**（L3层）：
```
no text anywhere, no letters words numbers labels logos signs trademarks, no readable content on walls objects documents screens clothing packaging
```

**生成方式**：
- **主来源**：global-negative-prompts.js 模块
- **动态注入**：ProductionEngine 根据镜头类型选择不同策略

**在渲染中的作用**：
- Seedance 负面提示词（negative prompt）
- 排除低质量/不符合要求的内容

---

### 3.22 【角色一致性】consistency

**业务含义**：跨镜头角色形象统一约束。

**应包含内容**：
```
保持陈卓角色形象一致，短发警服造型不变，面部特征与体型每帧统一，同一人出镜
```

**生成方式**：
- **主来源**：系统注入（基于角色定妆照）
- **PromptFusion 强化**：LLM 根据角色信息生成

**在渲染中的作用**：
- 配合定妆照，确保6个镜头的陈卓是同一个人
- 防止角色形象漂移

## 四、字段生产链路（完整数据流）

### 4.1 链路总图

```
用户意图输入
    ↓
[Layer 0] 需求清单确认（人工确认）
    ↓
[Layer 1] 剧本引擎（ScriptEngine）
    ├─ 意图解析 → 视频类型、风格、角色
    ├─ 剧本生成 → 场景列表、台词、角色动作
    ├─ 角色系统 → character对象（含portraitPaths）
    └─ 输出：ScriptBlueprint（6场景+台词+角色设定）
    ↓
[适配层] 格式转换
    ├─ 场景 → shot结构（timing/duration/sceneType）
    ├─ 角色 → character引用
    └─ 台词 → dialogueText
    ↓
[Layer 2] 制作引擎（ProductionEngine）
    ├─ [Phase 1] SceneDesignAgent → 【场景】描述
    ├─ [Phase 1] OpeningDesignAgent → 片头设计
    ├─ [Phase 2] VisualLanguageAgent → 【运镜】【动作】【情绪】运镜+动作+氛围
    ├─ [Phase 2] AudioDesignAgent → 【音频】音效+音乐
    ├─ [Phase 2] ContinuityReviewAgent → 连续性检查
    └─ [Phase 3] PromptFusionAgent → 22字段融合
    ↓
[导演技能] Hollywood Director Skills
    ├─ 剧情_斯皮尔伯格_雨夜手持.md → 增强动作+运镜
    ├─ 剧情_斯皮尔伯格_史诗斯坦尼康.md → 增强运镜+构图
    └─ 剧情_斯皮尔伯格_温情斯坦尼康.md → 增强情绪+灯光
    ↓
[FieldGuard] 字段校验
    ├─ 检查必填字段（约束/基础/场景/灯光/运镜/角色/动作/台词/负面约束）
    ├─ 检查定妆照引用
    └─ 检查负面提示词注入
    ↓
输出：6个镜头的完整提示词（含22字段）
```

### 4.2 各字段生成链路详解

#### 【灯光/照明】lighting

```
PromptFusionAgent LLM 生成
    ├─ 输入：场景类型（医院/宣教室/走廊）
    ├─ 输入：情绪阶段（冷静→紧张→警示）
    ├─ 输入：时间（白天/夜间/黄昏）
    └─ 输出：主光+补光+背景光+特效光
```

#### 【构图】composition

```
PromptFusionAgent LLM 生成
    ├─ 输入：场景类型（establishing=全景，climax=特写）
    ├─ 输入：角色位置（中央/黄金分割）
    └─ 输出：景别+主体位置+线条引导
```

#### 【色彩/色调】color_palette

```
PromptFusionAgent LLM 生成
    ├─ 输入：场景类型（医院=冷白偏青）
    ├─ 输入：情绪（温馨=暖调，紧张=冷调）
    └─ 输出：主色调+辅助色+肤色+饱和度+对比度
```

#### 【景深】depth_of_field

```
PromptFusionAgent LLM 生成
    ├─ 输入：景别（特写=f/1.4浅景深，全景=f/8深景深）
    ├─ 输入：焦点位置（面部/道具/环境）
    └─ 输出：焦点+光圈+前景/背景虚化+层次
```

#### 【运镜】camera_movement

```
VisualLanguageAgent（根据场景类型推断运镜）
    ├─ establishing → 缓慢推近/全景拉出
    ├─ conflict → 手持微晃/快速切换
    └─ emotional_climax → 稳定器跟拍/特写强化
    ↓
PromptFusionAgent 融合速度+稳定性+时间分布
```

#### 【服装】costume

```
PromptFusionAgent LLM 生成
    ├─ 输入：角色设定（警服）
    ├─ 输入：场景类型（正式/休闲）
    └─ 输出：外套+内搭+下装+鞋履+配饰
    ↓
服装锁定检查（v2.1.4-fix9-P4）：强制使用原始角色设定
```

## 五、字段质量检查清单

### 5.1 预生产输出检查

| 检查项 | 合格标准 | 检查工具 |
|--------|----------|----------|
| P0字段完整性 | 约束/基础/场景/灯光/运镜/角色/动作/台词/负面约束/一致性 | FieldGuard |
| 【灯光】专业性 | 含主光+色温+光质 | 正则检查 |
| 【构图】完整性 | 含景别+主体位置 | 正则检查 |
| 【色彩】完整性 | 含主色调+饱和度+对比度 | 正则检查 |
| 【景深】专业性 | 含焦点+光圈值 | 正则检查 |
| 【运镜】具体性 | 含运动方式+速度+时间分布 | 正则检查 |
| 【服装】详细性 | 含外套/内搭/下装/鞋履 | 正则检查 |
| 【时间轴】分段数 | ≥3段 | 正则检查 |
| 【节奏】完整性 | 含整体+开头+中段+高潮+结尾 | 正则检查 |
| 【转场】明确性 | 含切镜/淡入淡出/叠化 | 正则检查 |
| 负面约束注入 | 含"no text"+"禁止文字" | 关键字检查 |
| 定妆照路径 | 正确引用角色目录 | 文件存在检查 |

### 5.2 常见问题

| 问题 | 根因 | 解决方案 |
|------|------|----------|
| 字段缺失 | Phase-3预算不足走兜底 | 提升预算到20分钟 |
| 灯光不专业 | LLM缺乏灯光知识 | system prompt 给出标准格式示例 |
| 构图缺失 | 未定义该字段 | 恢复【构图】字段 |
| 色彩缺失 | 合并到【基础】 | 恢复【色彩/色调】字段 |
| 景深缺失 | 未定义该字段 | 恢复【景深】字段 |
| 运镜不具体 | 合并到【动作】 | 拆分【运镜】独立字段 |
| 服装不详细 | 合并到【角色】 | 拆分【服装】独立字段 |
| 时间轴错误 | LLM生成T00:00开始 | 修复system prompt定义 |
