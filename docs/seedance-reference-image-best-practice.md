## 一、问题现象

1. 定妆照提交后，视频中角色**未穿警服**（穿了运动装）
2. 台词**未生成**（视频无声）
3. 或台词**说随机内容**（不是 prompt 中的台词）

---

## 二、根本原因

### 2.1 服装被覆盖
- 仅上传定妆照不够
- Prompt 中的场景描述（如"健身房""运动"）会覆盖角色服装
- **必须在 prompt 中明确锁定服装**

### 2.2 台词未生成
- 未传 `generate_audio: true`
- Seedance 默认不生成音频

### 2.3 引用格式错误
- 使用 `@image1` 而不是官方要求的 `图片1`
- API 无法正确关联参考图

### 2.4 外观锚定不足
- 只写"穿警服"不够详细
- 必须描述警帽、警徽、肩章等标志性配饰

## 三、正确配置（缺一不可）

### 3.1 API Payload 结构

```json
{
  "model": "ep-20260518004622-jp46s",
  "content": [
    {
      "type": "text",
      "text": "16:9 cinematic | 穿警服的卡通3D女性角色示例角色，佩戴警帽警徽肩章，站在健身房中..."
    },
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {
        "url": "data:image/jpeg;base64,..."
      }
    }
  ],
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true
}
```

### 3.2 Prompt 关键规则

| 规则 | 错误示例 | 正确示例 |
|------|---------|---------|
| 必须锁定服装 | 站在健身房中 | **穿警服的**卡通3D女性角色站在健身房中 |
| 必须锚定配饰 | 穿警服 | 穿警服，**佩戴警帽、警徽、肩章、领花** |
| 引用格式 | @image1 中的角色... | **图片1** 中的穿警服女性角色... |
| 台词用纯文本 | 【台词】横纹肌溶解\|会导致... | 【台词】横纹肌溶解，会导致... |
| 避免敏感词 | 痛苦的表情 | **不适**的表情 |

### 3.3 提示词结构（主体→动作→场景→风格）

```
主体：穿警服的卡通3D女性角色示例角色，佩戴警帽警徽肩章
动作：双手叉腰，表情专注，正在休息恢复
场景：工业风健身工作室，杠铃哑铃散落
风格：16:9 cinematic, photorealistic
约束：警服款式颜色在所有场景中必须保持不变
```

### 3.4 多角度锚定

必须提供 **3-5 张** 定妆照：
- 正面全身/半身照
- 45度角半身照
- 侧面面部/半身照
- 面部特写（可选但推荐）

### 3.3 声音描述（新增）
- 在Prompt中描述环境音、音效、配乐，实现"视听一体化"
- 标记格式：`【音效】`、`【环境音】`、`【配乐】`
- 对白用引号括起来，追加 `EXACT, verbatim, no extra characters` 确保口型精准

### 3.4 多镜头叙事时间戳（新增）
- 在单条Prompt中规划分镜，使用 `[00:00-00:04]` 时间戳格式
- 结构：`[时间范围]，景别 + 运动 + 主体动作`
- 示例：`[00:00-00:04] 全景，展示城市夜景，镜头缓慢推进`

### 3.5 负向提示词（新增）
- 使用 `【负向】` 标记排除不想要的元素
- 示例：`【负向】模糊、变形、多余的肢体`

### 3.6 种子值锁定（新增）
- 批量生成同一角色时，统一设置 `seed` 值排除随机因素
- 确保微表情、衣纹走向等细节高度一致
- 格式：`seed:12345` 或 `seed=12345`

### 3.7 视频延长（Extend）
- 以上一段尾帧作为下一段首帧，实现无缝衔接
- 衔接处后期处理：前段末尾删6帧，后段开头删1帧
- 每段结尾保持"中性"姿态，为下段提供稳定起始状态

## 四、成本优化策略（新增）

### 4.1 预览-定稿工作流
- **创意探索阶段**：使用 `720p` 或 `Seedance 2.0 mini`（成本降低50%）
- **最终定稿阶段**：使用 `1080p` 标准版或Pro档
- `mini` 单秒成本约0.5元（720P），适合电商批量生成、UGC创作

### 4.2 定价参考
- 含视频输入（V2V）：28元/百万Tokens
- 不含视频输入（T2V/图生视频）：46元/百万Tokens
- 利用已有视频参考可降低成本约40%

### 4.3 片段拆分策略
- 生成较短片段（4-5秒）比长片段（10-15秒）单帧质量更高
- 长视频拆分为多个短片段分别生成，后期拼接
- 既能保证质量，又能精细控制每一秒内容

## 六、性能优化与调试

### 6.1 异步任务轮询（指数退避）
```python
def poll_with_backoff(job_id, max_wait=300):
    start = time.time()
    delay = 3
    while time.time() - start < max_wait:
        resp = get_job_status(job_id)
        if resp["status"] in ("completed", "failed"):
            return resp
        time.sleep(delay)
        delay = min(delay * 1.5, 15)  # 指数退避，最大15秒
    raise TimeoutError("任务超时")
```

### 6.2 限流与并发管理
- 默认有QPS和并发数限制，生产环境需申请提升额度
- 收到429错误时，实施指数退避重试，不要立即重试
- 批量任务采用异步队列，按预设速率平稳发送

### 6.3 常见错误排查
| HTTP状态码 | 含义 | 处理策略 |
|-----------|------|---------|
| 400 | 参数错误 | 检查提示词长度、分辨率、时长等 |
| 401 | 鉴权失败 | 验证API Key是否有效、未过期 |
| 429 | 超出速率限制 | 降低频率，实施指数退避重试 |
| 500 | 服务内部错误 | 重试2-3次，或降级到Fast档 |
| 503 | 服务暂不可用 | 等待30秒后重试，查看官方公告 |

系统已集成自动修复机制：

### 4.1 自动修复内容

| 检查项 | 自动修复动作 |

| 配饰未描述 | 添加"佩戴警帽警徽肩章" |
| 引用格式错误 | @image1 → 图片1 |
| 台词含竖杠 | \| → ， |
