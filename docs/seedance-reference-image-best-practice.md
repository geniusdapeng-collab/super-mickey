## 一、问题现象

1. 定妆照提交后，视频中角色**未穿警服**（穿了运动装）
2. 台词**未生成**（视频无声）
3. 或台词**说随机内容**（不是 prompt 中的台词）

---

## 二、根本原因

### 2.1 服装被覆盖
- 仅上传定妆照不够
- Prompt 中的场景描述（如"健身房""运动"）会覆盖角色服装
- **必须在 prompt 中明确锁定服装**

### 2.2 台词未生成
- 未传 `generate_audio: true`
- Seedance 默认不生成音频

### 2.3 引用格式错误
- 使用 `@image1` 而不是官方要求的 `图片1`
- API 无法正确关联参考图

### 2.4 外观锚定不足
- 只写"穿警服"不够详细
- 必须描述警帽、警徽、肩章等标志性配饰

---

## 三、正确配置（缺一不可）

### 3.1 API Payload 结构

```json
{
  "model": "ep-20260518004622-jp46s",
  "content": [
    {
      "type": "text",
      "text": "16:9 cinematic | 穿警服的卡通3D女性角色陈卓，佩戴警帽警徽肩章，站在健身房中..."
    },
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {
        "url": "data:image/jpeg;base64,..."
      }
    }
  ],
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true
}
```

### 3.2 Prompt 关键规则

| 规则 | 错误示例 | 正确示例 |
|------|---------|---------|
| 必须锁定服装 | 站在健身房中 | **穿警服的**卡通3D女性角色站在健身房中 |
| 必须锚定配饰 | 穿警服 | 穿警服，**佩戴警帽、警徽、肩章、领花** |
| 引用格式 | @image1 中的角色... | **图片1** 中的穿警服女性角色... |
| 台词用纯文本 | 【台词】横纹肌溶解\|会导致... | 【台词】横纹肌溶解，会导致... |
| 避免敏感词 | 痛苦的表情 | **不适**的表情 |

### 3.3 提示词结构（主体→动作→场景→风格）

```
主体：穿警服的卡通3D女性角色陈卓，佩戴警帽警徽肩章
动作：双手叉腰，表情专注，正在休息恢复
场景：工业风健身工作室，杠铃哑铃散落
风格：16:9 cinematic, photorealistic
约束：警服款式颜色在所有场景中必须保持不变
```

### 3.4 多角度锚定

必须提供 **3-5 张** 定妆照：
- 正面全身/半身照
- 45度角半身照
- 侧面面部/半身照
- 面部特写（可选但推荐）

## 四、自动化防护（PromptGuardian）

系统已集成自动修复机制：

### 4.1 自动修复内容

| 检查项 | 自动修复动作 |
|--------|-------------|
| 服装未锁定 | 添加"穿警服的"前缀 |
| 配饰未描述 | 添加"佩戴警帽警徽肩章" |
| 引用格式错误 | @image1 → 图片1 |
| 台词含竖杠 | \| → ， |
| 敏感词 | 痛苦→不适，血汗→体液 |

### 4.2 修复日志

所有自动修复记录到：
`output/prompt-guardian-log.json`

## 五、验证清单

提交前检查：
- [ ] `role: "reference_image"` 已指定
- [ ] `generate_audio: true` 已设置
- [ ] Prompt 明确锁定服装（如"穿警服的"）
- [ ] Prompt 描述标志性配饰（警帽、警徽等）
- [ ] 引用格式为"图片N"而非"@imageN"
- [ ] 台词纯文本，无竖杠 `|`
- [ ] 无敏感词（痛苦、受伤、血汗等）
- [ ] MIME 类型通过文件头检测
- [ ] 上传3-5张多角度定妆照
