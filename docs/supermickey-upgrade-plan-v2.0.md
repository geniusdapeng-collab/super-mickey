## 二、SuperMickey 当前独特优势（必须保留并放大）

1. **四层解耦架构** — 剧本→适配层→制作→渲染→后期，每层独立可替换
2. **创意指数引擎** — 0-1.0 精确控制创作强度，只影响"怎么拍"不影响"拍什么"
3. **风格编码器** — 6种主风格（REAL/CINE/POL/MINI/RET/FUT）+ 上下文感知
4. **需求清单确认** — Layer 0 焊死不可跳过，用户意图→结构化清单→人工确认
5. **基线热启动** — 历史模板复用，已验证的套路秒级复刻
6. **稳定性护盾** — 三层防护（基线注册表 + LLM熔断 + 健康监控）
7. **FieldGuard 25字段标准化** — 镜头字段完整性强制校验
8. **好莱坞技能注入** — 基于技能文件的动态导演增强

## 四、情绪价值强化方案（全链路）

> 视频本质是情绪产品。SuperMickey 的升级核心：让每一个环节都服务于最终的情绪输出。

### 4.1 情绪价值注入矩阵

| 链路环节 | 当前情绪能力 | 强化方向 | 实现模块 |
|----------|-------------|----------|----------|
| **需求解析** | ⚠️ 风格编码（6种） | 情绪意图识别 | `emotion-intent-parser.js` |
| **剧本生成** | ⚠️ 基础叙事 | 情绪弧线设计 | `emotion-arc-designer.js` |
| **镜头制作** | ⚠️ 好莱坞技能 | 情绪镜头语法 | `emotion-lens-grammar.js` |
| **提示词生成** | ⚠️ 标准化字段 | 情绪密度注入 | `emotion-density-injector.js` |
| **渲染输出** | ⚠️ 基础渲染 | 情绪色彩调色 | `emotion-color-grading.js` |
| **后期制作** | ⚠️ 基础字幕/音乐 | 情绪音乐匹配+字幕动效 | `emotion-post-suite.js` |
| **最终交付** | ❌ | 情绪价值报告 | `emotion-value-report.js` |

### 4.2 情绪价值核心模块设计

#### 模块 A：情绪意图解析器（EmotionIntentParser）
- **位置**：Layer 0，需求清单确认阶段
- **功能**：
  - 从用户意图中提取情绪目标（兴奋/温馨/紧张/治愈/震撼...）
  - 生成"情绪需求清单"，与功能需求并列
  - 情绪目标自动影响后续所有环节的默认参数

#### 模块 B：情绪弧线设计师（EmotionArcDesigner）
- **位置**：ScriptEngine 内部
- **功能**：
  - 基于剧本内容设计情绪曲线（起承转合）
  - 为每个场景分配情绪标签和强度
  - 确保全片情绪有起伏，避免平铺直叙

#### 模块 C：情绪镜头语法（EmotionLensGrammar）
- **位置**：ProductionEngine，与好莱坞技能注入并列
- **功能**：
  - 将情绪标签翻译为镜头语言（运镜、构图、光影、色彩）
  - 例如："温馨"→柔光+浅景深+缓慢推镜+暖色调
  - 与现有 cinematography-skill-router 协同工作

#### 模块 D：情绪密度注入器（EmotionDensityInjector）
- **位置**：提示词生成阶段
- **功能**：
  - 在提示词中注入情绪描述词汇
  - 控制每句话的情绪密度（避免过浓或过淡）
  - 与英文标准化兼容

#### 模块 E：情绪色彩调色（EmotionColorGrading）
- **位置**：RenderingEngine / PostProductionEngine
- **功能**：
  - 为渲染参数附加色彩风格指令
  - 支持 LUT 风格映射（电影级调色）

#### 模块 F：情绪后期套件（EmotionPostSuite）
- **位置**：PostProductionEngine
- **功能**：
  - 情绪匹配的背景音乐推荐
  - 字幕动效与情绪同步（紧张时抖动、温馨时淡入）
  - 音效情绪强化（心跳声、环境音等）

#### 模块 G：情绪价值报告（EmotionValueReport）
- **位置**：最终输出
- **功能**：
  - 生成全片情绪曲线图
  - 分析情绪峰值和谷值分布
  - 给出情绪优化建议

## 六、设计原则

1. **保留 SuperMickey 独特性**：四层架构、创意指数、风格编码、需求清单确认、基线热启动、稳定性护盾 — 这些不动，只增强。
2. **增强而非覆盖**：所有新功能通过配置开关控制，默认关闭，按需启用。
3. **情绪价值贯穿全链路**：不是加一个情绪模块，而是让每一个现有模块都增加"情绪视角"。
4. **渐进式集成**：每阶段独立验证，不阻塞现有流程。
5. **垂直场景可选**：商业广告、短视频、极限运动等作为可选模式，不污染通用链路。
