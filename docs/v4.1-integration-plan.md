## 一、融合策略概述

### 核心原则
1. **增量融合**：不破坏现有生产链路，逐步叠加v4.1规范
2. **上游控制**：新增Scene Card作为Shot Card的上游控制层
3. **底层约束**：Production Bible、Light Tier、优先级系统写入系统常量
4. **质量闭环**：五维评分 + 导演六问审片单，形成评审闭环

### 融合阶段

```
Phase 1: 系统常量层（立即）→ Phase 2: Scene Card层（1-2天）→ Phase 3: Shot Card增强（2-3天）→ Phase 4: Prompt模板升级（3-4天）→ Phase 5: 导演审片模块（4-5天）
```

## 三、Phase 2: Scene Card 层（上游控制）

### 3.1 新增模块：`agents/scene-card-agent.js`

在现有Shot Card生成之前，新增Scene Card生成环节。

**Scene Card是Shot Card的上游控制文档**，定义：
- 场次功能（建立/推进/冲突/揭示/回收）
- 场次目标（观众必须知道什么）
- 情绪曲线（从什么情绪到什么情绪）
- 光线总策略（本场Light Tier及变化）
- 色彩策略（Color Script）
- 轴线设定（180度线、屏幕方向）
- 连续性规划（哪些镜头必须strict）
- 风险评估
- 交付重点（Hero Shots）

**Scene Card 必填字段**（来自v4.1 3.3节）：

| 字段 | 映射到现有系统 | 状态 |
|------|---------------|------|
| 场次编号 | 新增 | 新增 |
| 场次功能 | 新增（现有"类型"字段不够） | 新增 |
| 场次目标 | 新增 | 新增 |
| 情绪曲线 | 现有"情绪"字段的扩展 | 增强 |
| 场景地点 | 现有"场景" | 兼容 |
| 时间状态 | 新增 | 新增 |
| 主要角色 | 现有"定妆照绑定" | 兼容 |
| 光线总策略 | 现有"照明方案"的升级 | 增强 |
| 色彩策略 | 新增（从Production Bible取） | 新增 |
| 节奏走势 | 新增 | 新增 |
| 轴线设定 | 新增 | 新增 |
| 连续镜头段 | 新增 | 新增 |
| 风险点 | 新增 | 新增 |
| 交付重点 | 新增 | 新增 |

### 3.2 Scene Card 生成时机

```
现有链路：故事需求 → Shot Card → Prompt → 渲染

v4.1链路：故事需求 → Scene Card → 【导演确认】→ Shot Card → Prompt → 渲染
```

## 四、Phase 3: Shot Card 增强（核心升级）

### 4.1 现有Shot Card字段 vs v4.1 Shot Card字段

| 现有字段 | v4.1字段 | 融合方式 |
|----------|----------|----------|
| 场景 | 所属场次 | 现有字段保留，新增"所属场次"关联 |
| 类型 | 镜头优先级 | 类型→优先级映射（building→P2, hero→P3, close→P2等） |
| 时长 | 建议入点/出点 | 扩展：增加节拍点和出入点建议 |
| 情绪 | 情绪目标 + 表演目标 | 拆分：情绪=情绪目标，新增表演目标 |
| 质量评分 | 五维评分 | 升级：从单一评分到五维评分 |
| 定妆照绑定 | 主体 + 角色锚点 | 升级：从绑定到锚点写法规范 |
| 视觉 | 叙事目的 + 主动作 + 空间关系 | 拆分：视觉→主动作+空间关系 |
| 环境布景 | 环境 + 空间关系 | 合并到空间关系字段 |
| 照明方案 | 光线档位 + 色温 | 升级：从描述到Light Tier代码 |
| 镜头时间轴 | 运镜 + 机位 + 景别 | 升级：从时间轴到专业运镜术语 |
| 嘴部动作 | 表演目标 | 合并到表演目标 |
| 环境音效 | 声音事件 | 兼容 |
| 导演优化建议 | 导演审片单 | 升级：从建议到六问审片单 |
| 无 | 起幅锚点(OFA) | 新增 |
| 无 | 落幅锚点(EFA) | 新增 |
| 无 | 镜内节拍点 | 新增 |
| 无 | 第一视觉重点 | 新增 |
| 无 | 屏幕方向 | 新增 |
| 无 | 视线方向 | 新增 |
| 无 | 连续性模式 | 新增 |
| 无 | 转场意图 | 新增 |
| 无 | 风险点 | 新增 |
| 无 | 失败容忍项 | 新增 |
| 无 | 是否Hero Shot | 新增 |
| 无 | 节奏四维标注 | 新增 |

### 4.2 新增字段详解

#### 起幅锚点 (OFA) / Opening Frame Anchor
- 起始构图与主体状态
- 景别初始状态
- 初始运动状态
- 光线初始状态

#### 落幅锚点 (EFA) / Ending Frame Anchor
- 最终主视觉对象
- 最终构图重心
- 情绪停点
- 下一镜连接点

#### 镜内节拍点 (In-Shot Beats)
- 2-4个关键动作节拍
- 每个节拍对应时间点和视觉变化

#### 第一视觉重点 (Primary Point of Interest)
- 观众第一眼必须看到什么
- 每镜头只允许一个

#### 屏幕方向 (Screen Direction)
- 左→右（前进/主动）
- 右→左（受阻/逆行）
- 向镜头（压迫/逼近）
- 离镜头（离开/逃避）

#### 节奏四维标注
| 维度 | 1分 | 5分 | 说明 |
|------|------|------|------|
| 节奏等级 | 静 | 爆发 | 整体节奏感受 |
| 信息密度 | 极简 | 高密 | 画面复杂度 |
| 情绪强度 | 平稳 | 强烈 | 情感冲击力 |
| 运动强度 | 静止 | 强运动 | 画面动态程度 |

## 五、Phase 4: Prompt 模板升级

### 5.1 v4.1 Prompt结构（替换现有模板）

现有模板：视觉描述堆砌，包含环境、照明、质感、时间轴等。

v4.1推荐结构：

```
1. 主体与绑定 (Subject & Character Anchor)
2. 主动作 (Primary Action)
3. 表演或反应重点 (Performance / Reaction Focus)
4. 空间环境 (Spatial Environment)
5. 镜头语言 (Camera Language)
6. 光线与材质 (Lighting & Material)
7. 声音/对白（如有）(Sound / Dialogue)
8. 收束锚点 (Closing Anchor / EFA)
```

### 5.2 Prompt构建原则（新增约束）

| 原则 | 说明 | 当前系统状态 |
|------|------|-------------|
| 关键信息前置 | 前80-120字优先放主体、动作、核心意图 | ⚠️ 当前视觉描述太长，主体被埋没 |
| 一镜一主旨 | 不允许一个镜头承载多个竞争事件 | ✅ 基本遵守 |
| 正向表达优先 | 描述想要什么，不堆叠不想要什么 | ❌ 当前有大量"NO..."负面描述 |
| 具象优先 | 可执行词汇 > 形容词 | ⚠️ 部分抽象词需要清理 |
| 可见差异优先 | 每一句对应可见变化 | ⚠️ 当前有冗余描述 |
| 少而准优于多而散 | 聚焦 > 覆盖 | ❌ 当前追求填满字符 |
| 忠于场次策略 | 单镜不得偏离场次光线/色彩/方向 | ⚠️ 需要Scene Card约束 |

### 5.3 长度控制原则（重大调整）

v4.1明确：**不以"写满"为目标**。

| 场景类型 | 建议长度 | 当前系统做法 |
|----------|----------|-------------|
| 简单动作镜/Insert | 120-220字符 | 当前追求990字符 |
| 标准叙事镜 | 220-420字符 | 当前追求990字符 |
| Hero Shot | 320-520字符 | 当前追求990字符 |
| 特殊长镜 | 按需扩展 | 当前追求990字符 |

**强制规则**：
- 不得为了提高利用率机械填充
- 若镜头主信息已完整，可接受低于旧版90%的利用率
- 超长时按优先级保留：主体→主动作→表演目标→空间关系→运镜→落幅→光线→声音

### 5.4 压缩优先级（当超长时）

```
1. 主体与绑定（不可删除）
2. 主动作（不可删除）
3. 表演目标（删除前需导演批准）
4. 空间关系（可简化但不可删除）
5. 运镜（可简化）
6. 落幅锚点（不可删除）
7. 光线/材质（可压缩为Light Tier代码）
8. 声音（可删除，由后期补充）
```

## 六、Phase 5: 质量评审与导演审片模块

### 6.1 五维成片导向评分（替换现有质量评分）

| 维度 | 权重 | 说明 | 评审标准 |
|------|------|------|----------|
| 可读性 | 25% | 主体、动作、空间是否一眼可辨 | 3秒内识别主体和动作 |
| 可控性 | 20% | 是否易于生成稳定结果 | 参考历史成功率与风险点 |
| 可剪性 | 20% | 是否方便接前后镜头 | 落幅锚点清晰，转场意图明确 |
| 情绪命中率 | 20% | 是否准确传达预期情绪 | 与Scene Card情绪目标对比 |
| 记忆点 | 15% | 是否有鲜明视觉钩子 | 是否有"一眼难忘"元素 |

### 6.2 评分等级

| 总分 | 等级 | 处理建议 |
|------|------|----------|
| 90-100 | 优秀 | 直接通过，可作为系列标杆 |
| 75-89 | 良好 | 通过，记录优化建议 |
| 60-74 | 合格 | 需修改后复审 |
| 40-59 | 不合格 | 需重写Shot Card和Prompt |
| 0-39 | 阻断 | 退回重新设计，不得渲染 |

### 6.3 导演审片六问（新增强制环节）

每镜头导演必须回答：

1. 这一镜存在的理由是什么？
2. 第一眼看哪里？
3. 如果删掉这镜，故事损失什么？
4. 这镜的落幅能否自然接下一镜？
5. 是否存在更简单、更准确的拍法？
6. 这镜是否"好剪"而不是仅仅"好看"？

### 6.4 阻断条件（新增强制检查）

以下任一出现即不得进入渲染：
- 主视觉中心不明确
- 多个动作竞争
- 运镜与动作冲突
- 起幅/落幅缺失
- 多角色同权重混乱
- 角色绑定不完整
- 明显不利于剪辑衔接
- 屏幕方向或视线接续逻辑不成立
- 违反系统约束或内容安全规范

| Scene Card增加审批环节延长周期 | 高 | 生产周期增加 | 模板化Scene Card，快速填充 |
| Prompt长度限制与新模板冲突 | 中 | 新模板可能更长 | 压缩优先级规则保障核心信息 |
| 团队适应成本 | 中 | 初期效率下降 | 过渡期并行运行，逐步切换 |
| 现有数据不兼容 | 低 | 历史数据无法复用 | 保留旧格式解析器，兼容读取 |
