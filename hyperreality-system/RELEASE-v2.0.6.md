# RELEASE v2.0.6 - 全中文字段名

## 发布日期
2026-06-20

## 变更摘要
将超级小香宝 Prompt 中所有英文字段名（dialogue: / mood: / timeline: / characterRef: / audio: 等）全面替换为中文【】字段名格式，与之前系统（卓越系统/超短裙系统）的字段体系对齐。

### 融合式架构说明
超级小香宝 v2.0.x 采用"融合式prompt"设计哲学：SceneDesignAgent 将场景、角色、动作、运镜、灯光、情绪等融为一段自然语言放入【场景】字段。这与之前系统的"结构化字段分离"架构不同，但字段名已统一为中文【】格式。
