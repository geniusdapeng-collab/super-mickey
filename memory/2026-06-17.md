**PromptForge 子进程（`promptforge-director-worker.js`）已经是 LLM 驱动。** 使用 `llm-reasoning-engine.js` 的 `LLMEngine`，单次 LLM 调用重写全部镜头 Prompt，子进程隔离防 OOM。这是 v6.5.52 的"方案F：超简化单次调用"设计。

## 13:52 队长提出的四个问题 - 根因定位报告

### 问题一：片头字段非标准 + 主标题错误 + 缺少副标题

**根因A（主标题错误）**：`extractOpeningConfig` 中 `episodeTitle` 的优先级是 `input.projectName || input.title`，而 `projectName` 的值是 `health-edu-ep01-rhabdo-v669`，所以主标题变成了项目ID。

**根因B（字段非标准）**：`opening-system-v3.js` 的 `generateGenericOpening` 直接硬编码了旧版字段：
- `【约束】` / `【基础】` / `【主体】` / `【质控】` / `【明亮约束】` / `【角色约束】`
- 这些字段名在标准规范中不存在（标准应为 `【视觉】`/`【动态】`/`【空间】`/`【风格】`/`【镜头时间轴】`/`【照明】`/`【负面约束】`/`【环境音效】`/`【渲染】`/`【导演】`/`【台词】`/`【人物介绍卡片】`）

**修复方案**：
1. `extractOpeningConfig`：`episodeTitle` 改为 `input.title || input.projectName`
2. `generateGenericOpening`：将 `fullPrompt` 改为标准字段格式
3. 添加副标题字段（从 `input.topic` 或 `input.series` 提取）

### 问题二：全局禁用 Narration（旁白/讲解词）

**根因**：`stageStoryboard`（Stage 7）中仍然保留了 `narration` 字段：
```javascript
narration: scene.narration || scene.dialogue || '', // 优先使用narration
```

Stage 7.3 只是“跳过修剪”，但**没有删除** narration 字段。

**修复方案**：在 Stage 7 的故事板生成中：
- 删除 `narration` 字段
- 如果 `scene.narration` 存在但 `scene.dialogue` 为空，将 `narration` 内容合并到 `dialogue`
- 只保留 `dialogue`

### 问题三：Dialogue 和 Visual Prompt 没有合并到提示词中

**根因**：`toStandardPrompt` 输出的是英文键值格式 `CHARACTER: ... | ACTION: ... | DIALOGUE: ...`，且被嵌套在 `【视觉】` 大括号内。标准格式应该是**独立的** `【台词】"完整台词内容"` 字段。

看 S01 的 Final Render Prompt：
```
【视觉】{CHARACTER: 陈卓... | DIALOGUE: 今天想和大家聊... | SCENE: ...}
```

这里 DIALOGUE 被嵌套在 `【视觉】` 内部，而不是独立的 `【台词】` 字段。

**修复方案**：在 `toStandardPrompt` 中：
1. 将英文键值 `CHARACTER: / ACTION: / SCENE: / ...` 改为中文标准字段 `【视觉】/【动态】/【空间】/ ...`
2. 添加独立的 `【台词】"完整台词内容"` 字段
3. 将 `【人物介绍卡片】` 作为独立字段（如果角色有定妆照）

### 问题四：PromptForge 关键环节由 LLM 驱动

**根因**：`core/promptforge-director-worker.js` 的 `callLLM` 函数中：
```javascript
const result = await engine.generate(prompt, { maxTokens: 8192 });
// result 是 { success: true, content: "...", ... } 对象
if (result && result.trim().length > 100) {  // ❌ 对象没有 .trim() 方法！
  return result.trim();
}
```

`engine.generate` 返回的是**对象**，但代码尝试对对象调用 `.trim()`，导致 `TypeError`，触发 catch 回退到本地合成。所以所有 Stage 1/2a/2b/3 都显示“回退到本地合成”。

**修复方案**：修改 `callLLM` 正确处理返回对象：
```javascript
const result = await engine.generate(prompt, { maxTokens: 8192 });
const text = result.content || result; // 优先取 content 字段
if (text && text.trim().length > 100) {
  return text.trim();
}
```
