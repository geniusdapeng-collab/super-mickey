## 2026-06-20 17:50 — 导演技能类型错误根因

### 问题
```
(shot.camera || shot.cameraMovement || "").toLowerCase is not a function
```

### 根因分析
在 `cinematography-skill-router.js` 的 `extractShotMetadata` 函数中：
```javascript
const cameraStr = (shot.camera || shot.cameraMovement || "").toLowerCase();
```

但 `shot.camera` 在生产引擎输出中是对象：
```json
{
  "shot_size": "wide",
  "movement": "dolly_in",
  "angle": "eye_level",
  "lens": "35mm",
  "speed": "slow"
}
```

对象是 truthy 的，所以 `shot.camera || ""` 返回对象，对象没有 `toLowerCase` 方法，导致报错。

### 修复建议
需要将 `shot.camera` 转换为字符串后再调用 `toLowerCase()`：
```javascript
const cameraStr = (typeof shot.camera === 'string' ? shot.camera : 
                   (shot.camera?.movement || shot.cameraMovement || "")).toLowerCase();
```

或直接从对象的 movement 字段提取：
```javascript
const cameraStr = (shot.camera?.movement || shot.cameraMovement || "").toLowerCase();
```

### 代码格式对比

**旧脚本 (`submit-unified-render.js`)** 和 **新核心 (`render-submitter-core.js`)** 的 `reference_image` 构造格式**完全一致**：
```javascript

  image_url: { url: 'data:image/png;base64,xxxxx' },
```

**关键差异**：旧脚本传4张全角度定妆照，新核心只传1张 front（注释：避免数据量过大导致 Seedance 内部错误）。

### 根本原因：MIME 类型与文件格式不匹配 🎯

**文件头检查**：
```bash
$ xxd /root/.openclaw/workspace/characters/chen-zhuo/portraits/chen-zhuo-front.png | head
00000000: ffd8 ffe0 0010 4a46 4946 0001 0101 0048  ......JFIF...H
```

- `ffd8 ffe0` → **这是 JPEG 格式文件头**
- 但文件扩展名是 `.png`
- `render-submitter-core.js` 根据扩展名设置 MIME 类型为 `image/png`

```javascript
// 当前代码（错误）
const mimeType = fullPath.endsWith('.png') ? 'image/png' : 'image/jpeg';
```

**Seedance API 解析过程**：
1. 收到 `data:image/png;base64,xxx` 
2. 尝试按 PNG 格式解析 JPEG 数据
3. 解析失败 → `InternalServiceError`

### 为什么6月13日 `chen-nurse` 成功？
- 同样存在 JPEG 伪装成 PNG 的问题（扩展名 `.png` 但文件头是 JPEG）
- 但6月13日使用的是旧脚本 `submit-unified-render.js`
- 旧脚本传4张全角度定妆照，可能 Seedance 对多图场景有不同的处理逻辑
- 或者旧脚本的 `reference_image` 顺序/结构有微妙差异

### 修复方案
修改 `render-submitter-core.js` 的 `buildPayload` 方法：
```javascript
// 用文件头检测真实格式，而非依赖扩展名
function detectMimeType(filePath) {
  const header = fs.readFileSync(filePath).slice(0, 4);
  if (header[0] === 0xFF && header[1] === 0xD8) return 'image/jpeg';  // JPEG
  if (header[0] === 0x89 && header[1] === 0x50) return 'image/png';   // PNG
  // fallback to extension
```

## Seedance 2.0 reference_image 提交标准方法（SOP）

### 适用场景
使用 Seedance 2.0 API 进行角色一致性渲染时，通过 reference_image 绑定定妆照。

### 前置条件
1. 定妆照必须是 **卡通/CG/3D渲染风格**（写实风格会触发 PrivacyInformation）
2. 文件格式支持：JPEG、PNG（推荐 JPEG，体积更小）
3. 图片尺寸：建议 512x512 至 2048x2048

### API 调用参数（标准格式）
```json
{
  "model": "ep-xxxx",
  "content": [
    {
      "type": "text",
      "text": "完整的视频提示词，包含镜头描述、角色动作、场景等"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "data:image/jpeg;base64,/9j/4AAQ..."
      },
      "role": "reference_image"
    }
  ],
  "ratio": "16:9",
  "duration": 10,
  "generate_audio": true,
  "watermark": true
}
```

### 关键参数说明
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | ✅ | 接入点ID，如 `ep-20260518004622-jp46s` |
| `content` | array | ✅ | 文本提示词 + reference_image |
| `content[0].type` | string | ✅ | `"text"` |
| `content[0].text` | string | ✅ | 视频生成提示词 |
| `content[1].type` | string | ✅ | `"image_url"` |
| `content[1].image_url.url` | string | ✅ | `data:image/jpeg;base64,...` 或 `https://...` |
| `content[1].role` | string | ✅ | `"reference_image"` |
| `ratio` | string | ✅ | `"16:9"` 或 `"9:16"` |
| `duration` | integer | ✅ | 视频时长（秒） |
| `generate_audio` | boolean | ✅ | **必须**设为 `true` |
| `watermark` | boolean | ✅ | **必须**设为 `true` |

### ❌ 禁止使用的参数
| 参数 | 说明 |
|------|------|
| `metadata` | Seedance 不支持 |
| `resolution` | Seedance 不支持 |
| `max_new_tokens` | 不适用视频生成 |

### MIME 类型检测方法
```javascript
function detectMimeType(filePath) {
  const header = fs.readFileSync(filePath).slice(0, 4);
  if (header[0] === 0xFF && header[1] === 0xD8) return image/jpeg;  // JPEG
  if (header[0] === 0x89 && header[1] === 0x50) return image/png;   // PNG
  return filePath.endsWith(.png) ? image/png : image/jpeg;
}
```

### 常见问题排查
| 错误码 | 原因 | 解决方案 |
|--------|------|----------|
| `InputImageSensitiveContentDetected.PrivacyInformation` | 图片被识别为真实人物 | 使用卡通/CG/3D风格定妆照 |
| `InternalServiceError` | MIME类型不匹配或参数错误 | 检查文件头 vs MIME类型；删除`metadata`/`resolution`；添加`generate_audio`/`watermark` |
| `BINDING_MANIFEST_INVALID` | 绑定清单路径错误 | 使用绝对路径或相对项目根目录的路径 |

- 官方文档: https://www.volcengine.com/docs/82379/2291680
- API端点: `https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`

## 2026-06-20 20:26 — 【重要纠正】视频质量不合格的真正原因

### 队长反馈
任务 `cgt-20260620200719-nbjrc` 渲染的视频有严重质量问题：
1. **定妆照没有生效**（角色形象不一致）
2. **画面内容不对**（场景/动作不符合 prompt）
3. **台词不对**（说了一堆乱七八糟的东西，不是 prompt 中的台词）

### 错误分析（此前分析完全错误）

**之前的错误结论**：以为是 API 参数问题（`watermark`, `generate_audio`, `metadata`, `resolution`），并写了错误的 SOP。

**真正原因**：是 `render-submitter-core.js` 的代码有两个严重 bug：

#### Bug 1: 只传1张定妆照（应为4张）
```javascript
// 错误代码（当前）
const primaryAngle = 'front';  // 只传1张

// 正确做法（6月13日成功版本）
// 传全部4个角度：front, threeQuarter, closeup, side
```
**影响**：Seedance 无法从1张正面照片推断角色的3D特征，导致角色识别失败，画面跑偏。

#### Bug 2: 添加了 `generate_audio: true`
```javascript
// 错误代码（当前）
generate_audio: true  // 让 Seedance 自由生成随机音频！

// 正确做法（6月13日成功版本）
// 不设置此参数（默认 false），不生成音频，后期用 TTS
```
**影响**：`generate_audio: true` 让 Seedance 根据场景"自由发挥"生成音频，完全无视 prompt 中的台词，导致"说了一堆乱七八糟的东西"。

### 6月13日成功任务 vs 当前失败任务对比

| 对比项 | 6月13日成功 (`submit-unified-render.js`) | 当前失败 (`render-submitter-core.js`) |
|--------|----------------------------------------|-------------------------------------|
| 定妆照数量 | **4张**（全角度） | **1张**（仅 front） |
| `generate_audio` | **无此参数**（默认 false） | **`true`** |
| `metadata` | 有 `max_new_tokens` | 无 |
| `resolution` | 无 | 无 |
| `watermark` | 无 | 有 |

**结论**：真正影响质量的只有前两项（定妆照数量和 `generate_audio`），其他参数不影响。

### 已修复

**`scripts/render-submitter-core.js` 修改**：
1. `buildPayload` 现在传 **4张全角度** 定妆照（front, threeQuarter, closeup, side）
2. 移除了 `generate_audio: true` 和 `watermark: true`
3. 恢复了正确的 payload 结构

### 教训
- **不要盲目相信官方文档的示例参数**（`generate_audio`, `watermark`）
- **要对比历史成功版本**，找出实际差异
- **错误的 SOP 会误导后续排查**，发现错误要立即删除/纠正
- **代码改动要有据可查**，不能私自简化逻辑（4张→1张）
