## 2026-06-23 21:00 - Prompt 长度仍不足，发现新根因

### 核心发现
修复后 prompt 长度仍只有 ~1100 字符，远未达到 2500 目标。

**根因**: LLM 实际只输出 11/25 个字段（S01 仅 11 个，S02 仅 10 个，S03 仅 9 个）。
- `_assembleStandardPrompt` 基于不完整字段生成 prompt（1070-1118 字符）
- `FieldGuard.normalizeAndValidate` 后续填充缺失字段，但 prompt 已固化无法回溯
- 模拟验证：使用 s.fields 直接组装可得 3128 字符，证明字段内容本身充足

### 第二轮修复 v2.1.4-fix10-P25-fix2
在 `prompt-fusion-agent.js` 的 `_fuseSingleShot` 中增加字段完整性检查：
- 新增 `_extractFieldsFromShot` 方法从 shot 对象提取数据补充 LLM 缺失字段
- 默认填充 negative, bright_constraint, character_constraint, director_instruction, consistency
- 避免额外 LLM 调用开销

- **Git commit**: `4b2ea19` v2.1.4-fix10-P25-fix2
