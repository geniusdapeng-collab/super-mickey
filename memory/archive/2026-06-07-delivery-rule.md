# 预生产交付规则

## 规则：预生产只发 MD 文件附件，不发飞书文档

**建立时间**: 2026-06-07
**版本**: v6.5.7

### 交付格式
- 预生产输出必须以 **Markdown 文件** 形式直接作为附件发送到飞书对话框
- 禁止以飞书文档形式发送预生产内容
- 附件命名规范：`taotie-ep01-preproduction-vX.Y.Z-prompts.md`

### 内容要求
MD 文件必须包含：
1. 所有镜头的完整最终 prompt（含【镜头时间轴】）
2. 提示词长度统计
3. 参考图绑定详情
4. 修复记录
5. 版本信息

### 参考图格式规范（v6.5.7 统一）
```
@image1 [A] 小G正面，银灰装甲，超写实
@image2 [B] 小G侧面，超写实
@image3 [C] 小G近景，超写实
@image4 [D] 小G另一侧面，超写实
@image5 [E] 饕餮正面，硅基巨兽，超写实
@image6 [F] 饕餮侧面，超写实
@image7 [G] 饕餮近景，超写实
@image8 [H] 饕餮另一侧面，超写实
```

**要素**：
- `@imageN`：API 引用标识
- `[字母]`：方括号+大写字母（A~H）
- `角色+角度`：描述内容（如"小G正面"）
- `核心特征`：角色关键视觉特征（如"银灰装甲"、"硅基巨兽"）
- `超写实`：风格特点

### 文件名/路径名对应
- 文件名中的角度信息必须与 prompt 描述对应
- 例如：`xiaoG-portrait-front_fullbody.png` → `小G正面`
