## 二、内容结构设计

### 2.1 内容边界（严格限定）

| 范围 | 包含 | 不包含（留给其他集） |
|------|------|---------------------|
| **本集（第二集）** | 横纹肌溶解的发生原因、常见诱因分析 | — |
| **第一集（已做）** | — | 症状表现、实验室检查指标 |
| **第三集（预留）** | — | 处理方法、预防措施、康复建议 |

**⚠️ 严禁越界**：本集只讲"为什么会发生"，不深入讲"症状是什么"（第一集已讲）和"怎么处理"（第三集要讲）。

### 2.2 预计镜头结构（导演参考）

| 镜头 | 预估时长 | 内容定位 | 情绪基调 | 景别建议 |
|------|---------|---------|---------|---------|
| S01 | 8-10s | 开场引入：提出核心问题"为什么剧烈运动后会横纹肌溶解？" | 引发好奇 | 中景→近景 |
| S02 | 10-12s | 原因1：过度运动/剧烈运动（最常见原因） | 警示 | 近景 |
| S03 | 10-12s | 原因2：肌肉挤压伤/外伤 | 严肃 | 近景 |
| S04 | 10-12s | 原因3：药物、毒素、感染等因素 | 专业 | 近景 |
| S05 | 8-10s | 原因4：高温环境/脱水等诱因 | 提醒 | 中景 |
| S06 | 8-10s | 总结：倾听身体信号，科学运动 | 正向引导 | 中景 |

**总计**：约 54-66秒，控制在59-65秒范围内。

### 2.3 台词设计原则

1. **开场钩子**：用问题引发好奇（"你知道为什么剧烈运动后会出现横纹肌溶解吗？"）
2. **中间展开**：逐条分析原因，每条配合具体例子
3. **结尾收束**：给出正向建议，不制造恐慌
4. **语言风格**：口语化、有节奏感，避免医学术语堆砌
5. **角色设定**：陈卓是健康教育主讲人，语气专业但亲和

## 六、制作技术要求

### 6.1 Prompt规范

| 层级 | 内容 | 控制方式 |
|------|------|---------|
| L1 约束层 | 画幅、帧率、无文本/字幕/水印 | 规则硬约束 |
| L2 基础层 | 超写实、电影质感、胶片颗粒 | 规则硬约束 |
| L3 场景层 | 环境、时间、天气、氛围 | LLM 创造性融合 |
| L4 角色层 | 角色形象、服装、动作 | LLM 创造性融合 |
| L5 动作层 | 肢体语言、走位、手势 | LLM 创造性融合 |
| L6 运镜层 | 景别、运动、角度 | LLM 创造性融合 |
| L7 灯光层 | 主光、辅光、氛围 | LLM 创造性融合 |
| L8 音效层 | 环境音、氛围音 | LLM 设计 |
| L9 质控层 | 无旁白、无配音、角色一致 | 规则硬约束 |

### 6.2 输出标准

- **Prompt长度**：≤1500字符（中文按1.5字符计算）
- **镜头时长**：精确到秒，总时长59-65秒
- **台词注入**：每镜头独立字段完整嵌入视觉Prompt
- **角色引用**：如定妆照存在，使用 `[character:陈卓]` 格式
