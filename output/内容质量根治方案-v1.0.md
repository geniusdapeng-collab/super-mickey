# 超现实系统 · 内容质量根治方案 v1.0

> 核心目标：确保【场景】【运镜时间轴】【台词】三个关键字段通过 LLM 高质量生成，并在全链路完整传递、逐级强化。
>
> 设计原则：信息不丢失、上下文逐级增强、LLM 每次都有完整导演指令。

---

## 一、当前系统架构 vs 目标架构

### 1.1 当前（有问题的）架构

```
User Intent ──→ ScriptEngine ──→ Adapter ──→ ProductionEngine
                   │               │              │
                   │           【信息黑洞】       │
                   │           description丢失   │
                   │           场景描述截断      │
                   │           主题信息丢失      │
                   │               │              │
                   ▼               ▼              ▼
              Layer 1输出      Layer 2输入      Agent Prompt
              完整丰富        极度贫乏        只有名字+50字梗概
```

### 1.2 目标架构

```
User Intent ──→ ScriptEngine ──→ Adapter ──→ ProductionEngine
                   │               │              │
                   │           【完整传递】       │
                   │           + 导演指令包      │
                   │           + 字段增强       │
                   │               │              │
                   ▼               ▼              ▼
              Layer 1输出      Layer 2输入      Agent Prompt
              完整丰富        完整+增强        导演指令+镜头信息
```

## 二、三大字段的生成与传递链路设计

### 2.1 【场景】字段

**当前问题**：
- Adapter 把场景压缩成 50 字 `prompt_base`
- SceneDesignAgent 输入只有场景类型（如"opening"），没有内容主题
- LLM 看不到"横纹肌溶解""科普""诊室"等关键信息

**修复方案**：

#### Step 1: 剧本引擎增强场景描述

ScriptGenerator 的 system prompt 需要明确要求输出完整的场景设定：

```javascript
// script-generator.js 增强
_scenePromptTemplate = `
为每个场景生成完整的导演设定：

1. setting: 具体地点（如：三甲医院检验科走廊，不是"户外"）
2. time_of_day: 具体时间（如：上午9:15，不是"清晨"）
3. atmosphere: 氛围关键词（3-5个）
4. visual_style: 视觉风格指引（如：冷白色荧光灯下的医院写实风格）
5. space_depth: 空间纵深描述（前景-中景-背景的具体内容）
6. key_props: 关键道具清单（如：抽血试管、检验报告单、听诊器）

要求：
- 场景必须与视频主题直接相关（医疗科普→医院/诊室/实验室）
- 禁止生成与主题无关的"安全场景"（如塑胶跑道、公园）
- 每个场景要有独特的空间定位和视觉差异
`;
```

#### Step 2: Adapter 完整传递场景字段

### 2.2 【运镜时间轴】字段

**当前问题**：
- 时间轴格式混乱（`T00:00-T00:08`，但没有累积时间）
- 运镜描述只有 30 字，没有具体的镜头运动规划
- 没有考虑镜头之间的衔接

**修复方案**：

#### Step 1: 剧本引擎输出精确时间轴

```javascript
// script-generator.js 增强时间轴
_generateTiming(scenes, targetDuration) {
  const timings = [];
  let currentTime = 0;
  
  for (const scene of scenes) {
    const duration = scene.timing?.duration || 10;
    const startTime = currentTime;
    const endTime = currentTime + duration;
    
    timings.push({
      scene_id: scene.scene_id,
      start: this._formatTime(startTime),
      end: this._formatTime(endTime),
      duration: duration,
      // 【新增】累积时间轴
      timeline: `T${this._formatTime(startTime)}-T${this._formatTime(endTime)}`
    });
    
    currentTime += duration;
  }
  
  return timings;
}

_formatTime(seconds) {
  const mins = Math.floor(seconds / 60);
  const secs = seconds % 60;
  return `${String(mins).padStart(2, '0')}:${String(secs).padStart(2, '0')}`;
}
```

#### Step 3: 时间轴全局校验

```javascript
// production-engine.js 新增时间轴校验
_validateTimeline(shots) {
  const errors = [];
  let currentTime = 0;
  
  for (let i = 0; i < shots.length; i++) {
    const shot = shots[i];
    const duration = shot.duration || 0;
    
    // 检查时间连续性
    if (shot.timeline_in !== undefined && shot.timeline_in !== currentTime) {
      errors.push({
        shot: shot.shotId,
        issue: `时间轴不连续: 期望 ${currentTime}s, 实际 ${shot.timeline_in}s`
      });
    }
    
    // 检查时长合理性
    if (duration < 3 || duration > 30) {
      errors.push({
        shot: shot.shotId,
        issue: `时长异常: ${duration}s (建议 3-30s)`
      });
    }
    
    currentTime += duration;
  }
  
  // 检查总时长
  const targetDuration = shots[0]?.blueprint?.target_duration || 60;
  if (Math.abs(currentTime - targetDuration) > 5) {
    errors.push({
      shot: 'TOTAL',
      issue: `总时长不匹配: 生成 ${currentTime}s, 目标 ${targetDuration}s`
    });
  }
  
  return errors;
}
```

### 2.3 【台词】字段

**当前问题**：
- 台词在剧本阶段生成后，没有在各环节被强化
- PromptFusion 中的台词字段格式混乱（`【台词】【台词】"内容"`）
- 没有校验台词是否与场景、情绪匹配

**修复方案**：

#### Step 1: 剧本引擎增强台词设计

```javascript
// script-generator.js 台词增强
_dialoguePromptTemplate = `
为每个场景设计台词，要求：

1. 专业度：使用准确的医学术语（如"肌酸激酶CK值"，不是"那个指标"）
2. 通俗性：复杂概念要有比喻解释（如"肌红蛋白是肌肉里的搬运工"）
3. 口语化：避免书面语，像真人说话（"大家注意啊"而不是"请注意"）
4. 情绪匹配：台词情绪与场景氛围一致（警示场景用短句、感叹句）
5. 时长控制：每句台词朗读时长 ≈ 镜头时长 - 2秒（留画面呼吸空间）
6. 禁止项：禁止预告下一集内容，禁止"未完待续"

台词设计原则：
- 开场钩子：第一句必须有冲击力（"尿液变成酱油色？这不是玩笑！"）
- 信息密度：每15秒传递1个核心知识点
- 记忆点：关键数据要重复或强调（"CK值超过5倍正常值"）
- 结尾收束：总结句要有行动号召（"记住，尿液变色就是红灯"）
`;
```

#### Step 2: 台词-场景一致性校验 Agent

新增 **DialogueConsistencyAgent**：

```javascript
// dialogue-consistency-agent.js（新增）
class DialogueConsistencyAgent extends BaseAgent {
  _getSystemPrompt() {
    return `你是一位剧本医生。检查台词与场景的一致性。

检查项：
1. 台词情绪是否与场景氛围匹配？
2. 台词内容是否与场景设定相关？
3. 台词时长是否在镜头时长范围内？
4. 专业术语是否准确？
5. 是否有"旁白/画外音"违规表述？

输出JSON:
{
  "checks": [
    {
      "shotId": "SC01",
      "pass": true/false,
      "issues": ["问题描述"],
      "suggested_dialogue": "修改建议（如需）"
    }
  ]
}`;
  }
  
  async process(shots, blueprint) {
    const prompt = this._buildPrompt(shots);
    const schema = { checks: [] };
    
    const result = await this._callLLM(prompt, schema);
    
    // 应用修复
    for (const check of result.checks || []) {
      if (!check.pass && check.suggested_dialogue) {
        const shot = shots.find(s => s.shotId === check.shotId);
        if (shot) {
          shot.dialogueText = check.suggested_dialogue;
        }
      }
    }
    
    return { shots, checks: result.checks };
  }
}
```

## 三、跨层上下文传递机制（DirectorContext）

### 3.1 设计理念

创建一个贯穿全链路的**导演指令包**，确保每个 Agent 都能看到完整的创作意图。

### 3.2 实现方案

```javascript
// shared/director-context.js（新增）
class DirectorContext {
  constructor(requirementList, intent) {
    this.title = requirementList.title || '';
    this.theme = this._extractTheme(intent);
    this.contentTheme = this._extractContentTheme(intent);
    this.visualStyle = requirementList.style?.primary || 'REAL';
    this.creativeIntensity = requirementList.creativeIntensity || 0.5;
    this.sceneRequirement = this._extractSceneRequirement(intent);
    this.characterDescription = this._extractCharacterDescription(requirementList);
    this.forbiddenScenes = this._extractForbiddenScenes(intent);
    this.seriesInfo = requirementList.series || null;
    this.keyMessages = this._extractKeyMessages(intent);
  }
  
  toPromptHeader() {
    return `## 🎬 导演指令
视频标题：${this.title}
内容主题：${this.contentTheme}
视觉风格：${this.visualStyle}
创意指数：${this.creativeIntensity}
场景要求：${this.sceneRequirement}
角色设定：${this.characterDescription}
关键信息：${this.keyMessages.join('；')}
禁止项：${this.forbiddenScenes.join('、')}
`;
  }
  
  toJSON() {
    return {
      title: this.title,
      theme: this.theme,
      contentTheme: this.contentTheme,
      visualStyle: this.visualStyle,
      creativeIntensity: this.creativeIntensity,
      sceneRequirement: this.sceneRequirement,
      characterDescription: this.characterDescription,
      forbiddenScenes: this.forbiddenScenes,
      keyMessages: this.keyMessages
    };
  }
  
  _extractTheme(intent) {
    // 从 intent 提取主题
    if (intent.includes('横纹肌溶解')) return '横纹肌溶解健康科普';
    return '通用科普';
  }
  
  _extractContentTheme(intent) {
    // 提取内容定位
    if (intent.includes('症状')) return '症状识别与实验室检查';
    if (intent.includes('原因')) return '发病原因分析';
    if (intent.includes('预防')) return '处理与预防';
    return '健康科普';
  }
  
  _extractSceneRequirement(intent) {
    // 根据主题推断场景要求
    if (intent.includes('横纹肌溶解')) {
      return '医院诊室、检验科、宣教室等与医疗检查相关的室内场景';
    }
    return '与主题相关的专业场景';
  }
  
  _extractCharacterDescription(requirementList) {
    const chars = requirementList.characters || [];
    return chars.map(c => `${c.name}：${c.description || '主讲人'}`).join('；');
  }
  
  _extractForbiddenScenes(intent) {
    const forbidden = [];
    if (intent.includes('横纹肌溶解') || intent.includes('医院')) {
      forbidden.push('户外跑道', '公园', '街道', '健身房');
    }
    return forbidden;
  }
  
  _extractKeyMessages(intent) {
    // 提取关键知识点
    const messages = [];
    if (intent.includes('CK')) messages.push('肌酸激酶CK是关键指标');
    if (intent.includes('肌红蛋白')) messages.push('肌红蛋白检测很重要');
    if (intent.includes('尿液')) messages.push('尿液变色是警示信号');
    return messages;
  }
}

module.exports = { DirectorContext };
```
