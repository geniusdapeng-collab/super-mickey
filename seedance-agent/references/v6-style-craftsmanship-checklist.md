## 优先级说明
- **P0（极高）**: 阻塞风格辨识度，必须先解决
- **P1（高）**: 显著提升风格质量，强烈建议尽快实施
- **P2（中）**: 锦上添花，有资源时实施
- **P3（低）**: 长期优化，非紧急

## 视觉层（shot-design / render-engine）

### P0 — 底层渲染范式替换
**编号**: VIS-01  
**问题**: "Seedance味" — 所有视频共享同一套3D国漫CG+自然光+写实底层  
**方案**: render-engine 实现4-5套可切换底层渲染范式：
- 写实胶片范式（诺兰/芬奇）
- 动画绘本范式（宫崎骏/韦斯安德森）
- 霓虹noir范式（王家卫/大卫芬奇）
- 纪录片范式（肯洛奇/达内兄弟）
**模块**: render-engine  
**依赖**: 无（架构级改动）

### P0 — 风格锚定机制
**编号**: VIS-02  
**问题**: 风格漂移 — 同视频内镜头间风格参数不一致  
**方案**: shot-design 前3秒通过关键帧确立风格基准参数集，后续镜头在容差范围内浮动（±15%）  
**模块**: shot-design  
**依赖**: VIS-01（需多范式支持）

### P1 — 视觉签名DNA跨镜头校验
**编号**: VIS-03  
**问题**: 五维覆盖只定义了"怎么拍单个镜头"，没定义"镜头间关系"  
**方案**: shot-design 增加跨镜头一致性约束 — 景别比例、主体位置、色温连续性  
**模块**: shot-design  
**依赖**: VIS-02

### P1 — 景别指纹系统
**编号**: VIS-04  
**问题**: 景别选择遵循功能逻辑而非气质驱动  
**方案**: 为每套风格定义景别比例指纹（诺兰70%全景/王家卫35%特写/韦斯安德森55%全景）  
**模块**: shot-design  
**依赖**: 无

### P1 — 光影锚点系统
**编号**: VIS-05  
**问题**: 光影参数镜头级独立，缺乏连续性  
**方案**: 全片光比波动≤±0.5档，主光源方向同场戏变化≤45度，阴影密度作为风格签名  
**模块**: shot-design + render-engine  
**依赖**: 无

### P1 — 全片色调轨迹
**编号**: VIS-06  
**问题**: 色调处理场景级，无全片叙事轨迹  
**方案**: 建立色调轨迹编辑器 — 渐变式/对照式/聚焦式三种叙事模式  
**模块**: render-engine + post-production  
**依赖**: 无

### P1 — 色调禁区（不可出现的颜色）
**编号**: VIS-07  
**问题**: 风格DNA中的"不可妥协"颜色未强制执行  
**方案**: 诺兰禁用荧光色，王家卫禁用纯白(#FFFFFF)，维伦纽瓦禁用高饱和暖色  
**模块**: render-engine  
**依赖**: 无

### P2 — 景别序列节奏指纹
**编号**: VIS-08  
**问题**: 景别序列随机组合，无内在节奏模式  
**方案**: 韦斯安德森稳定型序列（全景维持2-3镜），迈克尔贝压抑-释放型序列  
**模块**: shot-design  
**依赖**: VIS-04

## 叙事层（story-engine）

### P0 — 风格前置约束
**编号**: NAR-01  
**问题**: 风格是"外挂配件"而非"内生基因"，story-engine对风格无知  
**方案**: 风格DNA从项目源头注入，作为story-engine的"前置约束"而非shot-design的"后置参数"  
**模块**: story-engine  
**依赖**: 无（架构级改动）

### P1 — 风格化幕节奏
**编号**: NAR-02  
**问题**: 五幕均分（每幕20%），无风格辨识度  
**方案**: 每套风格定义独特幕节奏权重 — 诺兰高潮30%+合20%加速，王家卫承32%拉伸  
**模块**: story-engine  
**依赖**: NAR-01

### P1 — 信息揭示策略风格化
**编号**: NAR-03  
**问题**: 信息揭示无策略差异  
**方案**: 诺兰"延迟+轰炸"、希区柯克"观众全知+角色无知"、阿莫多瓦"碎片化+终点拼图"  
**模块**: story-engine  
**依赖**: NAR-01

### P1 — 叙事密度档位
**编号**: NAR-04  
**问题**: 叙事密度无风格分野  
**方案**: 高密度动作型(70/30)、均衡叙事型(55/45)、低密度文艺型(40/60)、超低密度实验型(20/80)  
**模块**: story-engine  
**依赖**: NAR-01

### P2 — 时间处理风格参数
**编号**: NAR-05  
**问题**: 时间压缩/延展无风格化语法  
**方案**: 诺兰精确分层(8:1时间比)、王家卫升格40-60%、林克莱特真实时间1:1、贝式跳切30-45次/分钟  
**模块**: story-engine + post-production  
**依赖**: NAR-01

## 对白层（dialogue-engine / voice-craft）

### P1 — 对白风格库
**编号**: DIA-01  
**问题**: 对白输出标准节奏，无风格适配  
**方案**: 6种风格对白指纹 — 昆汀(18-25词/句+俚语40%)、科恩(12-18词+方言35%)、Sorkin(22-30词+170-200词/分钟)、王家卫(8-12词+60-80词/分钟)  
**模块**: dialogue-engine  
**依赖**: 无

### P1 — 沉默预算系统
**编号**: DIA-02  
**问题**: 沉默使用无风格差异  
**方案**: 维伦纽瓦30%沉默、Sorkin 3-5%沉默、黑色电影15-20%沉默(武器化)  
**模块**: dialogue-engine + sound-design  
**依赖**: 无

### P2 — 角色行为风格滤镜
**编号**: DIA-03  
**问题**: 角色行为由情节驱动，无风格气质  
**方案**: 韦斯安德森滤镜(情感幅度上限40%+社交距离1.2米)、昆汀滤镜(自信120%+个人专属话题)、维伦纽瓦滤镜(语速-25%+沉默预备3秒)  
**模块**: character-manager + micromotion  
**依赖**: 无

### P2 — 角色-风格适配校验
**编号**: DIA-04  
**问题**: 任意角色可放入任意风格，无适配检查  
**方案**: 角色类型标签与风格参数匹配计算，低于阈值时触发"风格调和"提示  
**模块**: character-manager  
**依赖**: DIA-03

## 声音层（sound-design）

### P0 — 声音风格签名系统
**编号**: SND-01  
**问题**: 声音达到"功能正确"基线，无"一耳辨识度"  
**方案**: 四维声音DNA — 混响签名(RT60)、频率签名(EQ曲线)、动态签名(压缩比)、质感签名(底噪类型)  
**模块**: sound-design  
**依赖**: 无

### P1 — 配乐DNA系统
**编号**: SND-02  
**问题**: 配乐停留在"场景匹配"层面  
**方案**: 每套风格定义四个音乐DNA — 调式偏好、乐器组合、节奏型、和声复杂度  
**模块**: sound-design  
**依赖**: SND-01

### P1 — 声音效果风格化
**编号**: SND-03  
**问题**: 同一物理事件声音效果无风格差异  
**方案**: 同一枪声在诺兰/王家卫/科恩/贝/维伦纽瓦风格中完全不同处理  
**模块**: sound-design  
**依赖**: SND-01

### P2 — 静默密度参数
**编号**: SND-04  
**问题**: 静默使用无风格化  
**方案**: 维伦纽瓦25-30%(冥想)、诺兰12-15%(间隙)、贝3-5%(过载)、奉俊昊15-18%(硬切静默)  
**模块**: sound-design  
**依赖**: SND-01

## 后期层（post-production）

### P1 — 剪辑节奏模板
**编号**: POS-01  
**问题**: 剪辑节奏由情绪差值驱动，非风格签名  
**方案**: 三套基准模板 — 慢节奏冥想型(ALS 5-8秒/维伦纽瓦)、快节奏过载型(ALS 1-1.5秒/贝)、变奏张力型(ALS宽幅波动/诺兰)  
**模块**: post-production  
**依赖**: 无

### P1 — 心跳曲线风格指纹
**编号**: POS-02  
**问题**: 镜头时长分布无统计形态约束  
**方案**: 韦斯安德森正态分布(σ<0.6秒)、王家卫双峰分布(极慢6-15秒+极快0.3-1.2秒)  
**模块**: post-production  
**依赖**: POS-01

## 质量管控层

### P0 — 风格守卫（全链路校验）
**编号**: QUA-01  
**问题**: render-engine因prompt降级丢失色调参数  
**方案**: 每个节点输出后采样，与目标DNA比对，偏差超阈值时告警或修正  
**模块**: 全链路（v7.0 decision-engine调度 + v6.0各模块执行）  
**依赖**: 所有上述项

### P1 — 风格漂移检测（镜头级）
**编号**: QUA-02  
**问题**: 镜头间风格参数漂移未检测  
**方案**: 对比相邻镜头色温/光比/饱和度/阴影密度，同场景内严格阈值(色温±300K)，场景切换放宽(±800K)  
**模块**: v7.0 permission-gate + v6.0 shot-design  
**依赖**: VIS-02

### P1 — 盲测验证机制
**编号**: QUA-03  
**问题**: SRS内部指标可能自嗨  
**方案**: 将AI产出与真实影片混合编排，30人样本量，人机评分偏差控制在10%以内  
**模块**: 外部工具（非系统自动）  
**依赖**: QUA-01
