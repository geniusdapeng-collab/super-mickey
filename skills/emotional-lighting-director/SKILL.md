# Skill: emotional-lighting-director
# 情绪光影导演 - 根据情绪自动匹配光影方案

## 核心能力
基于金色色温情绪谱和三层金色模型，根据场景情绪自动设计光影方案。

## 情绪-光影映射表

| 情绪定位 | 色相偏移 | HEX参考 | 色温 | 照明方案 |
|----------|----------|---------|------|----------|
| 神圣庄严 | 偏黄 | #D4A574 | 4500K | 高轮廓光+体积光+冷暗部 |
| 温柔梦幻 | 偏玫瑰 | #E8B4A2 | 3800K | 柔光漫射+微粒金光+浅景深 |
| 清冷淡雅 | 偏白金 | #E5DCC3 | 6200K | 均匀漫射+冷轮廓+极简构图 |
| 苍凉史诗 | 偏暗赭 | #B8860B | 5200K | 侧光硬阴影+暖暗部+大景别 |
| 炽热激情 | 偏橙 | #E8985E | 3500K | 高对比+硬光+动态光效 |
| 未来科幻 | 偏柠檬 | #F0E68C | 5800K | 冷主光+金轮廓+数据粒子 |
| 自然有机 | 偏草金 | #C9B037 | 4800K | 自然光+漫射+环境反射 |

## 三层金色模型应用

```
┌─────────────────────────────────────────────────────────┐
│ Layer 1: 环境金 (Ambient Gold)                           │
│ 饱和度: 10-25% | 明度: 75-90% | 面积: 50-70%              │
│ 功能: 氛围基底，定义整体色温倾向                          │
│ 载体: 天光、雾气、散射光、浅色表面染色                      │
├─────────────────────────────────────────────────────────┤
│ Layer 2: 结构金 (Structural Gold)                        │
│ 饱和度: 35-55% | 明度: 55-75% | 面积: 15-25%              │
│ 功能: 视觉骨架，引导视线流动                              │
│ 载体: 金属结构、装饰线、产品边缘、文字                      │
├─────────────────────────────────────────────────────────┤
│ Layer 3: 高光金 (Highlight Gold)                         │
│ 饱和度: 55-80% | 明度: 85-100% | 面积: 5-15%               │
│ 功能: 视觉焦点，强调重点                                  │
│ 载体: 轮廓光、发光体、反射高光、粒子                        │
└─────────────────────────────────────────────────────────┘
```

## 输出模板
```
【情绪光影】[情绪类型]氛围：
主光[方案]，色温[色温]K
阴影[特征]，暗部色相[颜色]
色彩[倾向]，三层金色分配[环境]:[结构]:[高光]
整体[效果描述]
```

## 质量评分规则
- 情绪识别准确 = 5分
- 色温匹配正确 = 5分
- 三层金色分配合理 = 5分
- 暗部与亮部对比度 = 5分
- 最高20分（情绪维度满分）

## 调用接口
```javascript
const emotionalLight = await skills.invoke('emotional-lighting-director', {
  emotion: 'sacred' | 'romantic' | 'cool' | 'epic' | 'passionate' | 'futuristic' | 'organic',
  context: 'fashion' | 'food' | 'tech' | 'architecture' | 'nature' | 'ceremony' | 'art',
  intensity: 0.1-1.0
});
```
