# 后期合成制度 v1.0 - 通用型视频专用

## ⚠️ 适用范围

**适用于：** 科普视频、纪录片、产品介绍、教学视频、新闻播报等通用型视频

**不适用于：** 山海经系列（Nirath星球IP）、剧情片、纯视觉艺术片、音乐MV

---

## 1. 职责分离原则

| 环节 | 负责内容 | 禁止事项 |
|------|----------|----------|
| 视频生成API | 画面 + 口型动作 | ❌ 严禁依赖API自带音频 |
| TTS配音 | 说话内容 + 音频时长 | ❌ 严禁TTS音频超过视频时长 |
| 后期合成 | 音画同步 + 拼接 | ❌ 严禁保留API原声 |

---

## 2. 音色分配（固定）

| 角色 | 音色 | voice ID | 备注 |
|------|------|----------|------|
| 小陈/陈女士 | 女声 | zh-CN-XiaoxiaoNeural | 科普主持人 |
| AgentX | 童声 | zh-CN-XiaoyiNeural | 互动角色 |
| 其他角色 | 动态匹配 | 角色档案voice字段 | 按配置自动选择 |

---

## 3. 分辨率标准

- 目标分辨率：1920x1080 (16:9)
- 当前输出：1280x720（Seedance 2.0限制，下版升级）
- 升级路径：API支持1080p后自动切换

---

## 4. 输出规范

- ✅ TTS音频覆盖（完全替换API原声）
- ✅ 精确时长匹配（TTS ≤ 视频时长）
- ✅ 音画同步（-shortest参数保障）
- ❌ 不烧录字幕（除非队长特别要求）

---

## 5. 技术流程

### 5.1 生成TTS音频
```bash
edge-tts --voice zh-CN-XiaoxiaoNeural \
  --text "narration文本" \
  --write-media audio.mp3
```

### 5.2 替换视频音频
```bash
ffmpeg -i video.mp4 -i audio.mp3 \
  -c:v copy -c:a aac \
  -map 0:v:0 -map 1:a:0 \
  -shortest output.mp4
```

### 5.3 拼接最终视频
```bash
ffmpeg -f concat -safe 0 -i list.txt -c copy final.mp4
```

## 6. 质量校验清单

- [ ] TTS内容与narration 100%一致
- [ ] 音频时长 ≤ 视频时长
- [ ] 拼接前单镜试听确认
- [ ] 最终输出无API原声残留
- [ ] 音色与角色匹配

## 7. 山海经系列特殊规则

山海经系列（Nirath星球IP）不适用通用型TTS覆盖规则，采用**原声拼接方案**：

**规则：**
- ✅ 直接拼接原视频片段
- ✅ 保留原视频自带的声音和音效
- ❌ 不添加TTS配音
- ❌ 不烧录字幕
- ❌ 不动任何音频处理

**原因：**
- 山海经系列需要保持环境音、氛围音效、异兽叫声等原始音频
- 人工配音或TTS会破坏奇幻世界的沉浸感
- 原始模型生成的音效更符合异世界氛围

**操作流程：**
```bash
# 直接拼接原视频（不做任何音频处理）
ffmpeg -f concat -safe 0 -i list.txt -c copy final.mp4
```

**对比：**
| 项目类型 | 音频方案 | 字幕 | TTS |
|----------|----------|------|-----|
| 通用型（科普/纪录片） | TTS覆盖 | 按需 | ✅ |
| 山海经系列（Nirath） | 原声保留 | ❌ | ❌ |
