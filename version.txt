SuperMickey 版本唯一权威来源
============================

本仓库（SuperMickey 系统）的版本号只有一个权威来源：
  package.json 的 "version" 字段

当前版本：以 package.json 为准（本文件不登记具体数字，避免双写漂移）。

任何工具、脚本、AI Agent 需要确认"当前系统版本"时：
  - 只允许读取 package.json -> version
  - 禁止从 Git tag、tag 版本号比较、文档标题、目录名、
    子系统内部版本号推断"最新版本"

子系统内部编号说明（不是仓库版本，禁止当作 SuperMickey 版本）：
  - seedance-* 生产执行系统内部的 v6.x / v6.6.x 编号，
    是该子系统的历史内部编号，与 SuperMickey 系统版本号无关，
    不参与版本比较，不作为"最新版本"依据。
