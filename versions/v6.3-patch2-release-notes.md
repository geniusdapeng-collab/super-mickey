### 关键修复详情

#### 1. PromptForge 语法错误修复（v6.2-patch118）
- **问题**：`_buildCompositorPrompt` 结尾多写 `}`，导致 JavaScript 语法错误
- **后果**：`require('./promptforge-director')` 失败，PromptForge 完全被跳过
- **修复**：移除多余 `}`，PromptForge 可正常加载

#### 2. Seedance 2.0 角色绑定格式（v6.2-patch119）
- **之前**：`（人物形象严格参考图片1、图片2）`
- **之后**：`（@image1 作为AgentX角色形象参考，@image2 作为饕餮角色形象参考）`
- **API content**：`[{type:'text', text:prompt}, {type:'image_url', image_url:{url:'base64...'}, role:'reference_image'}]`

#### 3. 定妆照闸机 @image 检查（v6.2-patch120）
- **新增规则**：`seedanceBindFormat: true`（硬拦截）
- **检查项**：
  1. 必须使用 `@image` 格式绑定
  2. 禁止旧版"图片1"格式
  3. 必须包含 `@image` 引用
- **拦截消息**：明确提示使用 `@image1 作为角色形象参考` 格式

#### 4. LLM API abort 应对（v6.2-patch115）
- **问题**：白天 API 120秒 abort，timeout 600000ms 但 120秒被断开
- **修复**：`llm-reasoning-engine.js` `_callModel` 增加 abort 自动重试一次（timeout=300000ms），双重 fallback 保险

#### 5. PromptForge 精简输出模式（v6.2-patch118）
- **核心策略**：LLM 只生成 3000 字符创意内容（5个字段），系统模板自动拼接 4000-5000 字符固定约束
- **效果**：单次 LLM 调用 30-60秒（在 120秒安全线内），最终 Prompt 7000-8000 字符
